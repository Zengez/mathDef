A \emph{smooth rank-$k$ real vector bundle} over a smooth manifold $M$ is a smooth map $\pi:E\to M$ whose fibers $E_p=\pi^{-1}(p)$ are real vector spaces of dimension $k$ and which admits smooth local trivializations $\Phi:\pi^{-1}(U)\to U\times\mathbb R^k$ over open sets $U\subseteq M$. Each $\Phi$ restricts to a linear isomorphism on each fiber, and transition functions are smooth maps into $\operatorname{GL}_k(\mathbb R)$.
