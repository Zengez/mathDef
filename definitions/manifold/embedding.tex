% related: manifold.immersion, topology.topological-embedding
% source: https://ncatlab.org/nlab/show/smooth%2Bmanifold
% status: draft

A smooth map $F:M\to N$ is an \emph{embedding} if it is an immersion and a homeomorphism onto its image with the subspace topology.
