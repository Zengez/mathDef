% status: draft

A smooth map $F:M\to N$ is a \emph{smooth embedding} if it is an immersion (each differential $dF_p$ is injective) and a homeomorphism from $M$ onto $F(M)$ equipped with the subspace topology of $N$. It identifies $M$ with an embedded submanifold. An injective immersion need not be an embedding without the additional topological condition.
