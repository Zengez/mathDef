% id: manifold.smooth-map
% term: Smooth map between manifolds
% related: manifold.smooth-manifold, manifold.diffeomorphism
% source: https://ncatlab.org/nlab/show/smooth%2Bmanifold
% status: draft

A map $F:M\to N$ of smooth manifolds is \emph{smooth} if, in every pair of charts, its coordinate expression $\psi\circ F\circ\varphi^{-1}$ is $C^\infty$ wherever defined.
