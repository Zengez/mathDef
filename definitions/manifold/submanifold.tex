% term: Embedded submanifold
% related: manifold.smooth-manifold, manifold.embedding
% source: https://ncatlab.org/nlab/show/smooth%2Bmanifold
% status: draft

A subset $S\subseteq M$ is an \emph{embedded $k$-dimensional submanifold} if locally near each $p\in S$, a smooth chart sends $S$ onto the intersection of the chart image with $\mathbb R^k\times\{0\}$.
