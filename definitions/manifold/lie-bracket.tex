% id: manifold.lie-bracket
% term: Lie bracket of vector fields
% related: manifold.vector-field, manifold.lie-algebra
% source: https://ncatlab.org/nlab/show/smooth%2Bmanifold
% status: draft

For smooth vector fields $X,Y$, their \emph{Lie bracket} is the vector field $[X,Y]$ acting on smooth functions by $[X,Y]f=X(Yf)-Y(Xf)$.
