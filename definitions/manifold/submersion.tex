% term: Smooth submersion
% related: manifold.differential, manifold.immersion
% source: https://en.wikipedia.org/wiki/Submersion_(mathematics)
% status: draft

A smooth map $F:M\to N$ between smooth manifolds is a \emph{submersion} if its differential $dF_p:T_pM\to T_{F(p)}N$ is surjective at every $p\in M$. By the constant-rank theorem, it has local coordinate expressions equivalent to projections onto the first $\dim N$ coordinates. A submersion need not be globally surjective as a map of underlying sets.
