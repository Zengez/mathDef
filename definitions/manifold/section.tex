For a fiber bundle (or more generally a map) $\pi:E\to M$, a \emph{section} is a map $s:M\to E$ satisfying $\pi\circ s=1_M$. In the category of smooth bundles, a \emph{smooth section} is additionally smooth. Sections select one element from each fiber, and vector fields are smooth sections of the tangent bundle.
