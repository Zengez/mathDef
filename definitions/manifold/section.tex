For a map $\pi:E\to M$, a \emph{set-theoretic section} is a map $s:M\to E$ satisfying $\pi\circ s=1_M$. For a topological fiber bundle, a \emph{section} ordinarily means a continuous such map; a \emph{smooth section} of a smooth bundle is additionally smooth. Sections select one element from each fiber, and smooth vector fields are smooth sections of the tangent bundle.
