% id: manifold.differential
% term: Differential of a smooth map
% related: manifold.tangent-space, manifold.smooth-map
% source: https://ncatlab.org/nlab/show/smooth%2Bmanifold
% status: draft

For a smooth map $F:M\to N$ and $p\in M$, its \emph{differential} $dF_p:T_pM\to T_{F(p)}N$ is defined by $dF_p(v)(g)=v(g\circ F)$.
