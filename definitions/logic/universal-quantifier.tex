For a predicate $P(x)$ on a domain $D$, the \emph{universal quantifier} $\forall x\in D\,P(x)$ asserts that every element of $D$ satisfies $P$. Restricted universal quantification over an empty subset is true vacuously. In standard first-order model theory, the universe of a structure itself is usually required to be nonempty.
