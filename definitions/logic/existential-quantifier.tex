For a predicate $P(x)$ on a domain $D$, the \emph{existential quantifier} $\exists x\in D\,P(x)$ asserts that some element $a\in D$ satisfies $P(a)$. This statement is false when $D$ is empty. In ordinary first-order semantics domains are typically required to be nonempty, though restricted quantification may use an empty subset.
