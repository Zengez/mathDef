The \emph{material implication} $P\Rightarrow Q$ in classical propositional logic is false exactly when $P$ is true and $Q$ is false. It is equivalent to $\neg P\lor Q$. This truth-functional connective should be distinguished from semantic entailment $P\models Q$, which quantifies over interpretations.
