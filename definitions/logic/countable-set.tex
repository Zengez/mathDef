% term: Countable set
% related: sets.set, functions.bijection
% source: https://en.wikipedia.org/wiki/Countable_set
% status: draft

A set $A$ is \emph{countable} (at most countable) if it is finite or admits a bijection with $\mathbb N$. Equivalently, there exists an injection $A\to\mathbb N$. Some authors use \emph{countable} to mean countably infinite only, so the intended convention should be explicit.
