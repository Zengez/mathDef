% id: category.faithful-functor
% term: Faithful functor
% related: category.functor, category.full-functor
% source: https://ncatlab.org/nlab/show/category%2Btheory
% status: draft

A functor $F:\mathcal C\to\mathcal D$ is \emph{faithful} if each map $\mathcal C(X,Y)\to\mathcal D(FX,FY)$ is injective.
