% term: Preorder as a category
% related: category.category, category.poset-category
% source: https://en.wikipedia.org/wiki/Preorder
% status: draft

Every preorder $(P,\le)$ determines a category with objects $x\in P$ and exactly one arrow $x\to y$ when $x\le y$, otherwise none. Reflexivity provides identities and transitivity composition. Conversely, any category with at most one arrow between each two objects defines a preorder on its object collection. Antisymmetry is not required, so distinct isomorphic objects may occur.
