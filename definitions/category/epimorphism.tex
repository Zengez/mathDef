% term: Categorical epimorphism
% related: category.monomorphism, category.morphism
% source: https://en.wikipedia.org/wiki/Epimorphism
% status: draft

A morphism $f:A\to B$ in a category is an \emph{epimorphism} if it is right-cancellable: for any object $X$ and any $g,h:B\to X$, the equation $g\circ f=h\circ f$ implies $g=h$. Epimorphisms need not be surjective set maps in concrete categories, and an epimorphism need not be an isomorphism.
