An object $I$ of a category $\mathcal C$ is \emph{initial} if for every object $X$ there exists exactly one morphism $I\to X$. Initial objects, when they exist, are unique up to a unique isomorphism. An initial object is the colimit of the empty diagram, and the notion is dual to that of a terminal object.
