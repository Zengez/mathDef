% term: Zero object
% related: category.initial-object, category.terminal-object
% source: https://en.wikipedia.org/wiki/Zero_object_(algebra)
% status: draft

An object $0$ in a category is a \emph{zero object} if it is both initial and terminal: for every object $X$ there is exactly one morphism $0\to X$ and one morphism $X\to0$. A zero object, when it exists, is unique up to unique isomorphism and induces a distinguished zero morphism $X\to0\to Y$ for each pair $X,Y$.
