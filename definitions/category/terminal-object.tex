% status: draft

An object $T$ in a category $\mathcal C$ is \emph{terminal} if, for every object $X$, the set $\operatorname{Hom}_{\mathcal C}(X,T)$ has exactly one element. A terminal object, if it exists, is unique up to a unique isomorphism. It is the limit of the empty diagram and is dual to an initial object.
