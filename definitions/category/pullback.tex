% status: draft

Given a cospan $A\xrightarrow{f}C\xleftarrow{g}B$, a \emph{pullback} is an object $P$ with arrows $p_A:P\to A$, $p_B:P\to B$ satisfying $f p_A=g p_B$. For any object $X$ with arrows $a:X\to A$, $b:X\to B$ such that $fa=gb$, there is a unique $u:X\to P$ with $p_Au=a$ and $p_Bu=b$. A pullback is a limit of the cospan and need not exist in every category.
