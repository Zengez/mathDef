A \emph{morphism} $f:X\to Y$ in a category $\mathcal C$ is an element of the collection $\operatorname{Hom}_{\mathcal C}(X,Y)$, with domain $X$ and codomain $Y$. It is an abstract arrow admitting composition with appropriately typed morphisms, not necessarily a set-theoretic function. The identity $1_X$ is a morphism $X\to X$.
