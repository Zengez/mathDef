For a locally small category $\mathcal C$, a covariant functor $F:\mathcal C\to\mathbf{Set}$ is \emph{representable} if there exists $A\in\mathcal C$ with a natural isomorphism $F\cong\operatorname{Hom}_{\mathcal C}(A,-)$. Dually, a presheaf $G:\mathcal C^{\mathrm{op}}\to\mathbf{Set}$ is representable if $G\cong\operatorname{Hom}_{\mathcal C}(-,A)$. The representing object is determined up to isomorphism, not necessarily literal equality.
