% term: Covariant functor
% related: category.category, category.natural-transformation

% status: draft

A \emph{covariant functor} $F:\mathcal C\to\mathcal D$ sends each object $X$ to an object $F(X)$ and each arrow $f:X\to Y$ to an arrow $F(f):F(X)\to F(Y)$, preserving identity arrows and composition:
\[
F(1_X)=1_{F(X)},\qquad F(g\circ f)=F(g)\circ F(f).
\]
A contravariant functor is instead a covariant functor on the opposite category.
