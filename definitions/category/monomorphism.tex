% id: category.monomorphism
% term: Categorical monomorphism
% related: category.morphism, category.epimorphism
% source: https://ncatlab.org/nlab/show/category%2Btheory
% status: draft

A morphism $f:A\to B$ is a \emph{monomorphism} if $fg=fh$ implies $g=h$ for all pairs of morphisms $g,h:X\to A$.
