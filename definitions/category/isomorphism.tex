% term: Categorical isomorphism
% related: category.morphism, category.automorphism
% source: https://en.wikipedia.org/wiki/Isomorphism#Category_theory
% status: draft

A morphism $f:X\to Y$ in a category $\mathcal C$ is an \emph{isomorphism} if there exists $g:Y\to X$ with $g\circ f=1_X$ and $f\circ g=1_Y$. The inverse $g$ is unique, and an isomorphism is both a monomorphism and an epimorphism. The converse need not hold in an arbitrary category.
