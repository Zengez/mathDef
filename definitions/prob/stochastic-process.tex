A \emph{stochastic process} is a family $(X_t)_{t\in T}$ of random variables or random elements defined on a common probability space and indexed by a set $T$. The index often represents discrete or continuous time, and all variables usually take values in a common measurable state space. A path is the function $t\mapsto X_t(\omega)$ for a fixed outcome $\omega$.
