For real square-integrable random variables $X,Y$, their \emph{covariance} is $\operatorname{Cov}(X,Y)=E[(X-E[X])(Y-E[Y])]$, equivalently $E[XY]-E[X]E[Y]$. For complex-valued variables one usually conjugates one centered factor, so the real-valued convention should not be applied silently.
