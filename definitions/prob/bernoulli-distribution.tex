A real random variable $X$ has the \emph{Bernoulli distribution} with parameter $p\in[0,1]$, written $X\sim\operatorname{Bernoulli}(p)$, if $P(X=1)=p$ and $P(X=0)=1-p$. In particular, $P(X\in\{0,1\})=1$; the endpoint cases $p=0,1$ are degenerate distributions.
