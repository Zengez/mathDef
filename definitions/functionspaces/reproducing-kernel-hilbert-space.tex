A \emph{reproducing-kernel Hilbert space} (RKHS) on a set $X$ is a Hilbert space $\mathcal H$ of actual scalar-valued functions $f:X\to\mathbb C$ for which each evaluation map $\operatorname{ev}_x(f)=f(x)$ is a continuous linear functional. By the Riesz representation theorem, for each $x$ there is a unique kernel section $K_x\in\mathcal H$ with $f(x)=\langle f,K_x\rangle$, using the first-variable-linear inner-product convention. In particular, evaluation may be the zero functional at some points.
