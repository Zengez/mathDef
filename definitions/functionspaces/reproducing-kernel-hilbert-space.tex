A \emph{reproducing-kernel Hilbert space} $\mathcal H$ of scalar-valued functions on a set $X$ is a Hilbert space for which every point-evaluation map $\mathrm{ev}_x:f\mapsto f(x)$ is a bounded linear functional. Its reproducing kernel represents all evaluations by the inner product.
