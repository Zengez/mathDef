Let $\mathcal H$ be a vector space of complex-valued functions on $X$. A function $\varphi:X\to\mathbb C$ is a \emph{multiplier of $\mathcal H$} if $\varphi f\in\mathcal H$ for every $f\in\mathcal H$. The corresponding multiplication map is $M_\varphi f=\varphi f$.
