% term: Multiplier of a function space

For a complex linear space $\mathcal H$ of functions on a set $X$, a function $\varphi:X\to\mathbb C$ is a \emph{multiplier} if $\varphi f\in\mathcal H$ for every $f\in\mathcal H$. Multiplication defines the linear operator $M_\varphi f=\varphi f$. If $\mathcal H$ is a reproducing-kernel Hilbert space, this everywhere-defined multiplication operator is automatically bounded by the closed graph theorem. The collection of such $\varphi$ is its multiplier algebra.
