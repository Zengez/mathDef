% id: functions.surjective
% term: Surjective function
% aliases: Onto function
% related: functions.function, functions.bijection
% source: https://en.wikipedia.org/wiki/Surjective_function

A function $f:X\to Y$ is \emph{surjective} if every element of the codomain has a preimage:
\[
\forall y\in Y,\ \exists x\in X:\ f(x)=y.
\]
