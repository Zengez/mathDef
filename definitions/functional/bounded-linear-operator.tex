% id: functional.bounded-linear-operator
% term: Bounded linear operator
% related: functional.normed-space, functional.operator-norm

% status: draft

A linear map $T:X\to Y$ between normed spaces is \emph{bounded} if some $C\ge0$ satisfies $\|Tx\|_Y\le C\|x\|_X$ for all $x\in X$.
