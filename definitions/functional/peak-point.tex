% term: Peak point of a uniform algebra
% related: functional.uniform-algebra, functional.peak-function, functional.shilov-boundary
% source: https://encyclopediaofmath.org/wiki/Boundary_(in_the_theory_of_uniform_algebras)
% status: draft

For a uniform algebra $A\subseteq C(X)$, a point $x\in X$ is a \emph{peak point} if there exists $f\in A$ with $f(x)=1$ and $|f(y)|<1$ for all $y\in X\setminus\{x\}$.
