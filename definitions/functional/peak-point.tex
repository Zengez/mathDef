% id: functional.peak-point
% term: Peak point of a uniform algebra

% source: https://en.wikipedia.org/wiki/Shilov_boundary#Uniform_algebras
% status: draft

A point $x$ of the compact Hausdorff space $X$ is a \emph{peak point} for a uniform algebra $A\subseteq C(X)$ if there exists $f\in A$ with $f(x)=1$ and $|f(y)|<1$ for every $y\ne x$. Every peak point belongs to the Shilov boundary. In metrizable compact spaces, the set of peak points is dense in the Shilov boundary; for general compact Hausdorff spaces additional qualifications apply.
