% id: functional.nuclear-operator
% term: Nuclear operator between Banach spaces
% related: functional.banach-space, functional.continuous-dual
% source: https://en.wikipedia.org/wiki/Nuclear_operator
% status: draft

A bounded linear map $T:X\to Y$ of Banach spaces is \emph{nuclear} if there are $f_n\in X'$ and $y_n\in Y$ with $Tx=\sum_{n=1}^\infty f_n(x)y_n$ for all $x\in X$ and $\sum_{n=1}^\infty\|f_n\|\|y_n\|<\infty$.
