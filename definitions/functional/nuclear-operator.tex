% term: Nuclear operator between Banach spaces
% related: functional.banach-space, functional.continuous-dual
% source: https://en.wikipedia.org/wiki/Nuclear_operators_between_Banach_spaces
% status: draft

A bounded linear operator $T:X\to Y$ between Banach spaces is \emph{nuclear} if there are continuous linear functionals $\phi_n\in X^*$ and vectors $y_n\in Y$ such that
\[
Tx=\sum_{n=1}^\infty\phi_n(x)y_n,\qquad
\sum_{n=1}^\infty\|\phi_n\|\,\|y_n\|<\infty.
\]
The series converges in operator norm. Equivalently, $T$ lies in the image of the canonical map $X^*\widehat\otimes_\pi Y\to\mathcal B(X,Y)$; this map need not be injective.
