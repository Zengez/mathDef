% id: functional.peak-function
% term: Peak function for a uniform algebra
% related: functional.uniform-algebra, functional.peak-point
% source: https://en.wikipedia.org/wiki/Shilov_boundary#Uniform_algebras
% status: draft

Let $A\subseteq C(X)$ be a uniform algebra on a compact Hausdorff space $X$. A \emph{peak function at $x\in X$} is $f\in A$ with $f(x)=1$ and $|f(y)|<1$ for every $y\in X\setminus\{x\}$. Its existence makes $x$ a peak point. This is a strict pointwise inequality, not necessarily a uniform bound $|f|\le c<1$ outside $x$.
