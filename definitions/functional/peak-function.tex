% id: functional.peak-function
% term: Peak function for a uniform algebra
% related: functional.uniform-algebra, functional.peak-point
% source: https://encyclopediaofmath.org/wiki/Algebra_of_functions
% status: draft

For a uniform algebra $A\subseteq C(X)$ and $x\in X$, a \emph{peak function at $x$} is an $f\in A$ satisfying $f(x)=1$ and $|f(y)|<1$ for every $y\ne x$. Such an $x$ is a peak point.
