% id: functional.bounded-bilinear-form
% term: Bounded bilinear form
% related: functional.normed-space, linear.inner-product
% source: https://encyclopediaofmath.org/wiki/Functional_analysis
% status: draft

A bilinear map $B:X\times Y\to\mathbb F$ on normed spaces is \emph{bounded} if some $C$ satisfies $|B(x,y)|\le C\|x\|\|y\|$ for all $x,y$.
