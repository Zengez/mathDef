% term: Bounded bilinear form
% related: functional.normed-space, linear.inner-product
% source: https://en.wikipedia.org/wiki/Bilinear_form
% status: draft

A bilinear map $B:X\times Y\to\mathbb F$ on normed spaces is \emph{bounded} if some $C\ge0$ satisfies $|B(x,y)|\le C\|x\|\|y\|$ for all $x,y$.
