% id: functional.spectrum
% term: Spectrum of a bounded operator
% related: functional.banach-space, functional.resolvent-set
% source: https://encyclopediaofmath.org/wiki/Spectrum_of_an_operator
% status: draft

For $T\in\mathcal B(X)$ on a complex Banach space, the \emph{spectrum} $\sigma(T)$ consists of $\lambda\in\mathbb C$ for which $\lambda I-T$ has no bounded two-sided inverse.
