For decision languages $A,B\subseteq\{0,1\}^*$, a \emph{polynomial-time many-one reduction}, written $A\le_m^pB$, is a total polynomial-time computable map $f:\{0,1\}^*\to\{0,1\}^*$ such that $x\in A$ if and only if $f(x)\in B$ for every input $x$. This Karp reduction is more restrictive than a polynomial-time Turing reduction.
