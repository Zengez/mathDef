For a minimization problem with nonnegative optimal value $OPT(I)$ and feasible algorithm output $ALG(I)$, a \emph{$\rho$-approximation} satisfies $ALG(I)\le\rho\,OPT(I)$ for every instance, with $\rho\ge1$.
