A language $L\subseteq\{0,1\}^*$ lies in $\mathbf{BPP}$ if some probabilistic Turing machine halts within polynomially many steps for every input and every random-bit sequence, and outputs the correct answer with probability at least $2/3$ for each input. Both false acceptances and false rejections may occur. Replacing $2/3$ by any fixed constant greater than $1/2$ does not change the class, by error amplification.
