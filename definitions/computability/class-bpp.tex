A decision language $L$ belongs to $\mathbf{BPP}$ (bounded-error probabilistic polynomial time) if a randomized Turing machine runs in polynomial time on every input $x$ and returns the correct membership decision with probability at least $2/3$ for every $x$. The error may occur on either yes- or no-instances. Any fixed success threshold strictly greater than $1/2$ gives the same class after amplification.
