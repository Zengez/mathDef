A formal language $L\subseteq\Sigma^*$ is \emph{decidable} (recursive) if there is a Turing machine that halts on every input $w\in\Sigma^*$ and accepts exactly when $w\in L$. On inputs outside $L$ it must halt and reject; accepting members while possibly looping on nonmembers yields only recursive enumerability.
