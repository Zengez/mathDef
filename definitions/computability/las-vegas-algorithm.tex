A \emph{Las Vegas randomized algorithm} uses random choices but, whenever it returns an answer, that answer is correct. In the common convention it terminates almost surely and has finite expected running time on each input, although its running time may be unbounded over random executions. An alternative convention permits a distinguished failure symbol instead of an incorrect answer; the chosen convention should be stated.
