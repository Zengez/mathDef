In the \emph{decision-tree model} of computation, an algorithm is represented by a rooted tree whose internal nodes specify queries or tests, whose outgoing edges correspond to possible answers, and whose leaves specify outputs. The executed computation follows one root-to-leaf path; its number of queries is the path length. Worst-case query complexity is the maximum depth when this is finite.
