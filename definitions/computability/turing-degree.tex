For sets $A,B\subseteq\mathbb N$, write $A\equiv_T B$ when $A\le_T B$ and $B\le_T A$. The equivalence class $[A]_T$ is the \emph{Turing degree} of $A$. The degrees form a partially ordered set under $[A]_T\le[B]_T$ if and only if $A\le_T B$; this relation is independent of the representatives. The least degree $\mathbf 0$ contains exactly the computable sets.
