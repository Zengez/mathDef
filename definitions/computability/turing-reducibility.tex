For sets $A,B\subseteq\mathbb N$, one writes $A\le_T B$ and says that $A$ is \emph{Turing reducible} to $B$ if some oracle Turing machine, with access to membership queries for $B$, halts on every input and correctly decides membership in $A$. No complexity bound is imposed on the oracle computation. This is a weaker restriction than many-one reducibility.
