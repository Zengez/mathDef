The complexity class $\mathbf{NP}$ comprises languages $L\subseteq\{0,1\}^*$ for which there exist a polynomial $p$ and a deterministic polynomial-time verifier $V$ satisfying
\[
x\in L\quad\Longleftrightarrow\quad
\exists w,\ |w|\le p(|x|)\text{ and }V(x,w)=1.
\]
Equivalently, they are decidable by a nondeterministic Turing machine in polynomial time. The verifier must reject all proposed certificates for no-instances.
