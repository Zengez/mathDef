% term: Complexity class co-NP

% source: https://en.wikipedia.org/wiki/Co-NP
% status: draft

A language $L\subseteq\{0,1\}^*$ belongs to $\mathbf{coNP}$ precisely when its complement $\overline L$ belongs to $\mathbf{NP}$. Equivalently, there exist a polynomial $p$ and a polynomial-time verifier $V$ such that $x\notin L$ if and only if there is a certificate $w$ of length at most $p(|x|)$ with $V(x,w)=1$. It remains open whether $\mathbf{NP}=\mathbf{coNP}$.
