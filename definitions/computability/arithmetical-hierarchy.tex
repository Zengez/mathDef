The \emph{arithmetical hierarchy} classifies sets $A\subseteq\mathbb N$ by first-order formulas over arithmetic. For $n\ge1$, a set is in $\Sigma^0_n$ if its membership can be written using $n$ alternating blocks of unbounded number quantifiers, starting existentially, followed by a computable predicate; $\Pi^0_n$ starts universally. The class $\Delta^0_n=\Sigma^0_n\cap\Pi^0_n$ consists of sets definable in both ways. In particular, $\Sigma^0_1$ comprises the computably enumerable sets.
