For a deterministic Turing machine $M$ halting on every input, its \emph{worst-case time complexity} is $T_M(n)=\max_{\lvert x\rvert=n}\{\text{number of steps of }M\text{ on }x\}$. The computational model and input encoding must be specified when interpreting this complexity function.
