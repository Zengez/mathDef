A language $L$ belongs to $\mathbf{RP}$ if a randomized machine runs in worst-case polynomial time on every input and satisfies
\[
x\notin L\Longrightarrow\Pr(M(x)\text{ accepts})=0,\qquad
x\in L\Longrightarrow\Pr(M(x)\text{ accepts})\ge\tfrac12.
\]
There are no false positive acceptances, but false negatives are permitted. Repeated independent runs can make the false-negative probability arbitrarily small without introducing false positives.
