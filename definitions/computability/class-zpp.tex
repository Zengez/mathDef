A decision language belongs to $\mathbf{ZPP}$ (zero-error probabilistic polynomial time) if it has a randomized algorithm that always produces the correct answer, halts almost surely, and whose expected running time is bounded by a polynomial in input length. Equivalently, $\mathbf{ZPP}=\mathbf{RP}\cap\mathbf{coRP}$. Its expected polynomial bound need not be a worst-case polynomial bound.
