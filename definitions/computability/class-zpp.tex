A language lies in $\mathbf{ZPP}$ if some Las Vegas randomized algorithm always gives the correct answer whenever it halts, halts with probability one, and has expected running time bounded by a polynomial in the input length. The worst-case time can be unbounded. Equivalently, $\mathbf{ZPP}=\mathbf{RP}\cap\mathbf{coRP}$; another model uses worst-case polynomial time and permits a no-decision output with bounded probability.
