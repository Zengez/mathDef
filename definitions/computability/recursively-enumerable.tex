A formal language $L$ is \emph{recursively enumerable} if a Turing machine halts and accepts every input belonging to $L$, but does not accept inputs outside $L$. On nonmembers it is permitted to reject or run forever. Equivalently, the language has an effective enumeration; decidability additionally requires halting for every input.
