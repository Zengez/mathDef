A \emph{nondeterministic Turing machine} has a transition relation that may allow several next configurations from one configuration. Its computation on an input branches into possible paths; the input is accepted if at least one branch reaches an accepting state. For a nondeterministic decider, every branch must halt; standard time bounds constrain all computation branches.
