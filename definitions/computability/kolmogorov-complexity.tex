Fix an optimal universal partial computable machine $U:\{0,1\}^*\rightharpoonup\{0,1\}^*$. The \emph{plain Kolmogorov complexity} of a finite binary string $x$ is
\[
C_U(x)=\min\{|p|:U(p)=x\}.
\]
Any two optimal description machines yield complexities differing by at most an additive constant independent of $x$. The program domain need not be prefix-free; requiring prefix-free descriptions gives a related, generally different notion.
