A \emph{decision problem} asks, for each input instance $x$, for a yes-or-no answer. After fixing a finite encoding of the permitted instances, it can be represented as a language $L\subseteq\Sigma^*$, where $x\in L$ exactly when the answer is yes. Decidability and time complexity depend on a specified computational model and encoding.
