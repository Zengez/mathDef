% term: Big-Omega asymptotic notation
% related: computability.big-o, computability.big-theta
% source: https://en.wikipedia.org/wiki/Big_O_notation
% status: draft

In the standard algorithms/complexity convention, for eventually nonnegative functions $f,g:\mathbb N\to[0,\infty)$, $f(n)=\Omega(g(n))$ if there exist $c>0$ and $n_0$ such that $f(n)\ge c\,g(n)$ for all $n\ge n_0$. This is Knuth's eventual lower-bound convention; analytic number theory also uses a different, subsequential $\Omega$ notation.
