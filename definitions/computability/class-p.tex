The class $\mathbf P$ consists of decision languages $L\subseteq\{0,1\}^*$ for which some deterministic Turing machine halts on every input $x$, correctly decides membership $x\in L$, and runs in time bounded by a polynomial in the input length $|x|$. The exact choice of a standard finite encoding does not affect membership under polynomial-time interconversion.
