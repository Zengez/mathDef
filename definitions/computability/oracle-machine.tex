An \emph{oracle Turing machine} is a Turing machine furnished with a primitive query operation for a fixed oracle set $B\subseteq\mathbb N$: it may ask whether $n\in B$ and receives the correct yes-or-no answer as one oracle step. The relative computation may decide sets not computable without the oracle. The oracle's answers are treated as given, rather than computed by the querying machine.
