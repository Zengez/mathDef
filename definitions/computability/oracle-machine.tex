An \emph{oracle Turing machine} is a Turing machine with an additional operation that asks membership queries of a fixed set $B\subseteq\mathbb N$ (the \emph{oracle}). A query about $n$ returns whether $n\in B$, treated as one primitive step in the standard oracle computation model. Computations may thus be described as being \emph{relative to $B$}, even when $B$ is not decidable by an ordinary Turing machine.
