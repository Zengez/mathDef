For a topological space $X$ and a point $x\in X$, a set $N\subseteq X$ is a \emph{neighborhood of $x$} if there is an open set $U$ with $x\in U\subseteq N$. Thus a neighborhood need not itself be open. An \emph{open neighborhood} is a neighborhood that is open in $X$.
