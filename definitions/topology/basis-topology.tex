A family $\mathcal B$ of subsets of a set $X$ is a \emph{basis for a topology} if each point of $X$ belongs to some $B\in\mathcal B$, and whenever $x\in B_1\cap B_2$ for $B_1,B_2\in\mathcal B$, there is $B_3\in\mathcal B$ with $x\in B_3\subseteq B_1\cap B_2$. The topology generated by $\mathcal B$ consists of arbitrary unions of elements of $\mathcal B$. Equivalently, for an existing topology, a family of open sets is a basis exactly when each open set is such a union.
