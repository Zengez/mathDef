A topological space $X$ is \emph{path-connected} if for every pair $x,y\in X$ there is a continuous map $\gamma:[0,1]\to X$ with $\gamma(0)=x$ and $\gamma(1)=y$. Path connectedness implies connectedness, but the converse fails for general spaces. Under the literal universal-quantifier convention the empty space is path-connected, since there are no pairs of points to check. Some authors instead require a path-connected space to be nonempty (equivalently, to have exactly one path component), in which case the empty space is excluded.
