% term: Closed set
% related: topology.open-set, topology.interior
% source: https://en.wikipedia.org/wiki/Closed_set

A subset $F\subseteq X$ of a topological space $(X,\tau)$ is \emph{closed} if $X\setminus F$ is open. Arbitrary intersections and finite unions of closed sets are closed. In a non-Hausdorff space, a singleton need not be closed. The empty set and all of $X$ are both closed and open.
