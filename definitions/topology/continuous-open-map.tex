A map $f:X\to Y$ between topological spaces is an \emph{open map} if $f(U)$ is open in $Y$ for every open set $U\subseteq X$. This is logically independent of continuity for general maps, because continuity requires preimages of open sets to be open. An open bijection automatically has a continuous inverse, but need not itself be continuous; it is a homeomorphism precisely when it is also continuous.
