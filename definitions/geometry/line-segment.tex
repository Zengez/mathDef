For points $p,q$ in a real affine space, the \emph{closed line segment} joining them is
\[
[p,q]=\{(1-t)p+tq:0\le t\le1\}.
\]
If $p=q$ this is the singleton $\{p\}$. The corresponding open segment, when $p\ne q$, uses $0<t<1$.
