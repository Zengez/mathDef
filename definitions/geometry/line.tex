An \emph{affine line} in $\mathbb R^n$, $n\ge1$, is a set $\ell=\{p+tv:t\in\mathbb R\}$ with $p\in\mathbb R^n$ and nonzero direction vector $v\in\mathbb R^n$. Different nonzero scalar multiples of $v$ determine the same line. An affine line is a one-dimensional affine subspace.
