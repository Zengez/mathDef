A \emph{Boolean measure-preserving action} is a Borel map $\alpha:G\times X\to X$ with measure-preserving bijections $\alpha_g$ such that $\alpha_{gh}(x)=\alpha_g(\alpha_h(x))$ for $\lambda$-almost all $x$, separately for each $g,h\in G$.
