A sequence $(a_n)$ in an ordered set is \emph{nondecreasing} if $a_{n+1}\ge a_n$ for all indices $n$, and \emph{nonincreasing} if $a_{n+1}\le a_n$ for all $n$. Either type is \emph{monotone}; the terms \emph{increasing} and \emph{decreasing} sometimes denote strict versions, so the inequalities should be stated explicitly.
