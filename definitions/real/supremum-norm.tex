For a bounded real- or complex-valued function $f$ on a nonempty set $X$, its \emph{supremum norm} is $\|f\|_\infty=\sup_{x\in X}|f(x)|$. It is a finite norm on the vector space of all bounded scalar-valued functions on $X$. No measure is involved; the essential-supremum norm on $L^\infty$ is a different construction.
