A map $f:(X,d_X)\to(Y,d_Y)$ is \emph{Lipschitz continuous} if there exists $L\ge0$ such that $d_Y(f(x),f(y))\le Ld_X(x,y)$ for every $x,y\in X$. Every such $L$ is a Lipschitz constant; a map with some $L<1$ is a contraction when it maps a metric space into itself.
