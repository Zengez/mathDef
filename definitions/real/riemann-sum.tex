For a function $f:[a,b]\to\mathbb R$, a partition $a=x_0<x_1<\cdots<x_n=b$, and tags $\xi_i\in[x_{i-1},x_i]$, the associated \emph{Riemann sum} is $\sum_{i=1}^{n}f(\xi_i)(x_i-x_{i-1})$. The partition mesh is $\max_i(x_i-x_{i-1})$.
