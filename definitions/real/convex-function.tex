Let $C$ be a convex subset of a real vector space. A function $f:C\to\mathbb R$ is \emph{convex} if for every $x,y\in C$ and $t\in[0,1]$,
\[
f((1-t)x+ty)\le(1-t)f(x)+tf(y).
\]
The inequality uses the usual order on $\mathbb R$; extended-real-valued convex functions require a separate convention.
