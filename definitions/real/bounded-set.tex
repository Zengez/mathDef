% id: real.bounded-set
% term: Bounded subset of the real line
% related: real.supremum, real.infimum
% source: https://en.wikipedia.org/wiki/Bounded_set
% status: draft

A set $A\subseteq\mathbb R$ is \emph{bounded} if there exists $M\ge0$ such that $|a|\le M$ for every $a\in A$; equivalently, $A$ is bounded both above and below. The empty set is bounded under this definition.
