A bounded function $f:[a,b]\to\mathbb R$ ($a<b$) is \emph{Riemann integrable} if its lower and upper Darboux integrals coincide. Their common finite value is $\int_a^b f(x)\,dx$. Equivalently, the tagged Riemann sums converge to the same value as the mesh of the partitions tends to zero, uniformly over choices of tags.
