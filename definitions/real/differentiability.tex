A function $f:I\to\mathbb R$ on an open interval is \emph{differentiable at} $a\in I$ if the finite limit $\lim_{h\to0}(f(a+h)-f(a))/h$ exists. Equivalently, there is a real number $L$ such that $f(a+h)=f(a)+Lh+o(|h|)$ as $h\to0$; then $L=f'(a)$.
