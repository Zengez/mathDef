% id: numerical.newton-root
% term: Newton's method for a scalar root
% related: numerical.fixed-point-iteration, real.derivative
% source: https://en.wikipedia.org/wiki/Newton%27s_method
% status: draft

For differentiable $f:\mathbb R\to\mathbb R$, \emph{Newton iteration} is $x_{k+1}=x_k-f(x_k)/f'(x_k)$ whenever $f'(x_k)\ne0$.
