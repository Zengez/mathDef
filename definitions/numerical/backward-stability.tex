% id: numerical.backward-stability
% term: Backward stable algorithm
% related: numerical.backward-error, numerical.roundoff-error
% source: https://encyclopediaofmath.org/wiki/Numerical_analysis
% status: draft

An algorithm is \emph{backward stable} under a specified finite-precision model if its computed output solves a nearby input problem exactly, with backward error bounded proportionally to machine precision under stated assumptions.
