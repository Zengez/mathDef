An algorithm is \emph{backward stable} on a specified class of problems if its computed output is an exact solution of a nearby input problem with backward error controlled by a small multiple of the unit roundoff (and suitable problem-dependent scaling), subject to explicit arithmetic and input assumptions. It is an algorithmic property, not the same as good conditioning.
