\emph{Gaussian elimination} is an algorithm reducing a matrix or linear system to row-echelon form using elementary row operations, with row exchanges (pivoting) when needed to avoid a zero pivot. In exact arithmetic, row-echelon reduction is always possible for a matrix over a field.
