For a numerical problem represented by $f:A\to X$, given input $a$ and computed output $\widetilde x$, the \emph{absolute backward error} (in a specified norm on the input space) is $\inf\{\|\delta a\|:a+\delta a\in A,\ f(a+\delta a)=\widetilde x\}$. The infimum may not be attained, and it is $+\infty$ if no such perturbation exists.
