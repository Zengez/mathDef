% source: https://encyclopediaofmath.org/wiki/Numerical_analysis
% status: draft

For a computed approximation $\widetilde x$ to a problem with input $a$, the \emph{backward error} is the size of the smallest perturbation $\delta a$ for which $\widetilde x$ exactly solves the perturbed problem $a+\delta a$.
