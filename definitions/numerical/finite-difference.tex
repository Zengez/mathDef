% status: draft

For $h>0$ and a real function $f$ defined near $x$, the \emph{centered finite-difference quotient} is $(f(x+h)-f(x-h))/(2h)$, an approximation to $f'(x)$. If $f$ is $C^3$ near $x$ with bounded third derivative, the truncation error is $O(h^2)$.
