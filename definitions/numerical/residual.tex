% term: Residual of a linear system
% related: numerical.least-squares, numerical.forward-error
% source: https://en.wikipedia.org/wiki/Residual_(numerical_analysis)
% status: draft

For a linear system $Ax=b$ over a normed field and an approximate solution $\widetilde x$, the \emph{residual vector} in the convention used here is $r=b-A\widetilde x$. Some authors define its negative $A\widetilde x-b$ instead. A small residual need not imply a small forward error for an ill-conditioned system.
