% id: numerical.convergence-order
% term: Order of convergence of an approximation
% related: numerical.discretization-error, numerical.finite-difference
% source: https://en.wikipedia.org/wiki/Order_of_accuracy
% status: draft

For $p>0$, a family $u_h$ approximating $u$ as $h\downarrow0$ has \emph{at least order-$p$ accuracy} in a specified norm if $\|u_h-u\|\le C h^p$ for all sufficiently small $h$, with $C$ independent of $h$.
