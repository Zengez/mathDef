% id: numerical.convergence-order
% term: Order of convergence of an approximation
% related: numerical.discretization-error, numerical.finite-difference
% source: https://encyclopediaofmath.org/wiki/Numerical_analysis
% status: draft

A family of approximations $u_h$ has \emph{error order $p$} in a specified norm if $\|u_h-u\|\le C h^p$ for all sufficiently small $h$, with $C$ independent of $h$.
