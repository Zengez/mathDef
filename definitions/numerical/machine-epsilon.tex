For a specified floating-point system, \emph{machine epsilon} is the distance from $1$ to the next larger representable floating-point number. The related \emph{unit roundoff} is the maximum relative error for rounding a real number to a floating-point number under a specified rounding rule; for typical binary round-to-nearest arithmetic, it is half the gap above $1$. Both quantities have been called machine epsilon in different sources.
