A \emph{finite matroid} is a pair $M=(E,\mathcal I)$, with finite ground set $E$ and family $\mathcal I\subseteq\mathcal P(E)$ of \emph{independent sets}, satisfying: (i) $\varnothing\in\mathcal I$; (ii) if $I\in\mathcal I$ and $J\subseteq I$, then $J\in\mathcal I$; (iii) if $I,J\in\mathcal I$ and $|I|<|J|$, some $e\in J\setminus I$ satisfies $I\cup\{e\}\in\mathcal I$. This exchange axiom generalizes linear and graphic independence.
