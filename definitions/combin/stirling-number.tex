For integers $n,k\ge0$, the \emph{Stirling number of the second kind} $\left\{\begin{smallmatrix}n\\k\end{smallmatrix}\right\}$ counts the partitions of an $n$-element labelled set into exactly $k$ nonempty unlabelled blocks. In particular $\left\{\begin{smallmatrix}0\\0\end{smallmatrix}\right\}=1$ and the count is $0$ for $k>n$.
