% status: draft

For a finite matroid $M$ on ground set $E$, with rank function $r$, its \emph{Tutte polynomial} is $T_M(x,y)=\sum_{A\subseteq E}(x-1)^{r(E)-r(A)}(y-1)^{|A|-r(A)}$.
