The \emph{$n$th Bell number} $B_n$, for $n\ge0$, is the number of ways to partition an $n$-element set into nonempty, pairwise disjoint blocks. By the empty-partition convention $B_0=1$. Equivalently, $B_n=\sum_{k=0}^n S(n,k)$, where $S(n,k)$ is a Stirling number of the second kind.
