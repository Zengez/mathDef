% id: metric.open-set
% term: Open set
% aliases: Metric-open set
% related: metric.metric-space, metric.open-ball, topology.open-set

A subset $U$ of a metric space $(X,d)$ is \emph{open} if for every $x\in U$ there is an $\varepsilon>0$ for which
\[
B_{\varepsilon}(x)\subseteq U.
\]

This definition induces a topology on $X$.
