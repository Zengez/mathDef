For a self-map $f:X\to X$, a set $A\subseteq X$ is \emph{forward invariant} if $f(A)\subseteq A$; every forward iterate of a point of $A$ then remains in $A$. The stronger equality $f(A)=A$ means that $f$ maps $A$ onto itself; it does not in general imply backward invariance $f^{-1}(A)\subseteq A$. A set is \emph{backward invariant} if $f^{-1}(A)\subseteq A$, and \emph{completely invariant} in the forward-and-backward sense if both inclusions hold (equivalently, $f^{-1}(A)=A$). In particular, for a surjective self-map, complete invariance implies $f(A)=A$. Some authors use \emph{invariant} for $f(A)\subseteq A$ and others for $f(A)=A$. For a two-sided flow $(\varphi_t)_{t\in\mathbb R}$, an \emph{invariant} set satisfies $\varphi_t(A)=A$ for every real $t$.
