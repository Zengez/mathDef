% term: Forward invariant set

% status: draft

For a self-map $f:X\to X$, a set $A\subseteq X$ is \emph{forward invariant} if $f(A)\subseteq A$; every forward iterate of a point of $A$ then remains in $A$. The stronger condition $f(A)=A$ is often called \emph{invariance}. For a flow $(\varphi_t)_{t\in\mathbb R}$, invariance means $\varphi_t(A)=A$ for every real $t$.
