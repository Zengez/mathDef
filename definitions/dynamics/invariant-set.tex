For a self-map $f:X\to X$, a set $A\subseteq X$ is \emph{forward invariant} if $f(A)\subseteq A$; every forward iterate of a point of $A$ then remains in $A$. The stronger property $f(A)=A$ is sometimes called \emph{full} or \emph{complete invariance}. Terminology varies: some authors call the weaker condition $f(A)\subseteq A$ simply \emph{invariance}. For a two-sided flow $(\varphi_t)_{t\in\mathbb R}$, an \emph{invariant} set satisfies $\varphi_t(A)=A$ for every real $t$.
