A fixed point $p$ of a metric dynamical system is \emph{Lyapunov stable} if for every $\varepsilon>0$ some $\delta>0$ ensures $d(x,p)<\delta$ implies $d(f^n(x),p)<\varepsilon$ for all $n\ge0$.
