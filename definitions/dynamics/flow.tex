A \emph{(continuous) flow} on a topological space $X$ is a jointly continuous map $\varphi:\mathbb R\times X\to X$, written $\varphi_t(x)$, such that $\varphi_0=\operatorname{id}_X$ and $\varphi_{s+t}=\varphi_s\circ\varphi_t$ for all $s,t\in\mathbb R$. Each $\varphi_t$ is a homeomorphism with inverse $\varphi_{-t}$. If only $t\ge0$ is allowed, the corresponding notion is a \emph{semiflow}.
