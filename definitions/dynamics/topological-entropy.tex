For a continuous map $f$ on a nonempty compact metric space $(X,d)$, set $d_n(x,y)=\max_{0\le j<n}d(f^j(x),f^j(y))$. Let $s(n,\varepsilon)$ be the maximum cardinality of a set with $d_n(x,y)>\varepsilon$ for all distinct members. The \emph{topological entropy} is
\[
h_{\mathrm{top}}(f)=\lim_{\varepsilon\downarrow0}\limsup_{n\to\infty}\frac1n\log s(n,\varepsilon).
\]
This Bowen--Dinaburg definition is independent of the choice of compatible metric on compact $X$, and can take the value $+\infty$.
