% term: Periodic point
% related: dynamics.fixed-point, dynamics.orbit
% source: https://en.wikipedia.org/wiki/Periodic_point
% status: draft

A point $x\in X$ is \emph{periodic} for a self-map $f:X\to X$ if $f^n(x)=x$ for some integer $n\ge1$. The smallest such integer is its \emph{least} or \emph{prime period}. A fixed point has least period $1$, and a point of least period $n$ has exactly $n$ distinct elements in its forward orbit.
