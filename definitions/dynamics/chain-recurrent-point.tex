Let $f:X\to X$ be a continuous map of a metric space $(X,d)$. An \emph{$\varepsilon$-chain from $x$ to $y$} is a finite sequence $x=x_0,x_1,\ldots,x_m=y$, $m\ge1$, for which $d(f(x_i),x_{i+1})<\varepsilon$ for $0\le i<m$. A point $x$ is \emph{chain recurrent} if for every $\varepsilon>0$ there is an $\varepsilon$-chain from $x$ back to itself. Flow versions typically impose both an error tolerance and a minimum time per segment.
