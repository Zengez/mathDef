% term: Radical ideal
% related: commalg.radical-ideal, algebra.ideal
% source: https://en.wikipedia.org/wiki/Radical_of_an_ideal
% status: draft

An ideal $I$ of a commutative ring $R$ is \emph{radical} if $I=\sqrt I$, equivalently if $r^n\in I$ entails $r\in I$ for every $n\ge1$.
