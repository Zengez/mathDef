% term: Integral element over a ring

% status: draft

For a homomorphism $\varphi:A\to B$ of commutative rings and $b\in B$, the element $b$ is \emph{integral over $A$} if $b$ satisfies a monic polynomial whose coefficients lie in $\varphi(A)$. The ring map is an \emph{integral extension} if every $b\in B$ is integral over $A$.
