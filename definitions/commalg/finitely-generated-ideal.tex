% id: commalg.finitely-generated-ideal
% term: Finitely generated ideal
% related: algebra.ideal, commalg.noetherian-ring
% source: https://stacks.math.columbia.edu/tag/00FM
% status: draft

For a commutative ring $R$, an ideal $I\subseteq R$ is \emph{finitely generated} if $I=(a_1,\ldots,a_n)=\{\sum_{i=1}^n r_ia_i:r_i\in R\}$ for some finite list of elements of $I$.
