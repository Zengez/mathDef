% id: relations.maximal-element
% term: Maximal element
% related: relations.partial-order, relations.maximum-element
% source: https://en.wikipedia.org/wiki/Maximal_and_minimal_elements
% status: draft

An element $m$ of a partially ordered set $(P,\le)$ is \emph{maximal} if there is no $x\in P$ with $m<x$, where $m<x$ means $m\le x$ and $m\ne x$. A maximal element need not be comparable with every other element and need not be greatest; a poset may have several maximal elements or none.
