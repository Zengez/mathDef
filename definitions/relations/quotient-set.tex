% id: relations.quotient-set
% term: Quotient set by an equivalence relation
% related: relations.equivalence-class, relations.equivalence-relation
% source: https://encyclopediaofmath.org/wiki/Partially_ordered_set
% status: draft

For $\sim$ on $X$, its \emph{quotient set} $X/{\sim}$ is the set of all equivalence classes $[x]$ for $x\in X$.
