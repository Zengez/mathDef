% term: Quotient set by an equivalence relation
% related: relations.equivalence-class, relations.equivalence-relation

% status: draft

For an equivalence relation $\sim$ on a set $X$, its \emph{quotient set} $X/{\sim}$ is the set $\{[x]_\sim:x\in X\}$ of all equivalence classes. The canonical quotient map $q:X\to X/{\sim}$ sends $x$ to $[x]_\sim$ and is surjective. Different representatives determine the same class exactly when they are equivalent.
