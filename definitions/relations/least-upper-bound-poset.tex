For $A\subseteq P$ in a poset $(P,\le)$, a \emph{join} (supremum, or least upper bound) $\bigvee A$, if it exists, is an element $s\in P$ with $a\le s$ for every $a\in A$ and $s\le u$ for every other upper bound $u$. Such an element is unique but need not exist in an arbitrary poset.
