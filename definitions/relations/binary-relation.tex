A \emph{binary relation} from a set $A$ to a set $B$ is a subset $R\subseteq A\times B$. The notation $aRb$ means $(a,b)\in R$. A relation \emph{on} $A$ is a subset of $A\times A$, allowing reflexivity, symmetry and transitivity to be defined.
