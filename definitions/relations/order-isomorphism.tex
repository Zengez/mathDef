An \emph{order isomorphism} between partially ordered sets $(P,\le_P)$ and $(Q,\le_Q)$ is a bijection $f:P\to Q$ such that $x\le_P y$ exactly when $f(x)\le_Q f(y)$. Equivalently, $f$ and $f^{-1}$ are both order-preserving; it is a surjective order embedding.
