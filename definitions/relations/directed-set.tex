A \emph{directed set} is a nonempty preordered set $(D,\le)$ in which each pair $a,b\in D$ has a common upper bound $c\in D$ satisfying $a\le c$ and $b\le c$. The relation need not be antisymmetric. Directed sets supply the index domains for nets in topology.
