A \emph{greatest element} (maximum) of a partially ordered set $(P,\le)$ is an element $g\in P$ satisfying $x\le g$ for every $x\in P$. If it exists, it is unique and is maximal. A maximal element need not be greatest; the converse implication fails in general.
