% term: Upper bound in a poset
% related: relations.partial-order, relations.least-upper-bound-poset
% source: https://en.wikipedia.org/wiki/Upper_and_lower_bounds
% status: draft

For a subset $A$ of a partially ordered set $(P,\le)$, an element $u\in P$ is an \emph{upper bound} of $A$ if $a\le u$ for every $a\in A$. An upper bound need not belong to $A$ and need not be the least upper bound. Every element of $P$ is an upper bound of the empty subset.
