A \emph{complete lattice} is a partially ordered set $L$ in which every subset $A\subseteq L$ has both a least upper bound $\bigvee A$ and a greatest lower bound $\bigwedge A$ in $L$. The empty subset is included, so a complete lattice has a greatest element $\bigwedge\varnothing$ and a least element $\bigvee\varnothing$.
