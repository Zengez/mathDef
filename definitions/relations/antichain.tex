In a partially ordered set $(P,\le)$, an \emph{antichain} is a subset $A\subseteq P$ such that for distinct $a,b\in A$, neither $a\le b$ nor $b\le a$. The empty set and singletons are antichains. Maximal antichains under inclusion need not have maximum cardinality.
