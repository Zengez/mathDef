A nonempty finite undirected graph is \emph{$k$-regular} if every vertex has degree exactly $k$. For a simple graph on $n$ vertices this implies $0\le k\le n-1$ and $nk$ is even. For the empty graph, the vacuous-degree convention must be specified separately.
