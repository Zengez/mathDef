An \emph{independent set} in a simple undirected graph $G=(V,E)$ is a subset $I\subseteq V$ with no edge joining any two distinct vertices of $I$, equivalently with $G[I]$ edgeless. Its maximum possible cardinality is the independence number $\alpha(G)$. The empty subset is always independent.
