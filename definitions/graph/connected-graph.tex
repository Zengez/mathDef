A nonempty undirected graph $G$ is \emph{connected} if for every pair of vertices $u,v$ there exists a finite path from $u$ to $v$. A one-vertex graph is connected via a length-zero path. Some texts also call the empty graph connected by vacuity; this entry uses the nonempty convention.
