A \emph{simple undirected graph} is a pair $G=(V,E)$, where $V$ is a vertex set and $E\subseteq\{\{u,v\}:u,v\in V,\ u\ne v\}$ is a set of two-element subsets called edges. This model has no loops or parallel edges. Directed graphs, multigraphs and graphs with loops require different edge conventions.
