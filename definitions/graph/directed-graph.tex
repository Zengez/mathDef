A \emph{directed graph} (digraph) is a pair $(V,E)$ with vertex set $V$ and arc set $E\subseteq V\times V$. An arc $(u,v)$ has source $u$ and target $v$. This relation-based convention allows loops $(v,v)$ but not parallel copies of the same arc; directed multigraphs require additional edge data.
