A \emph{proper vertex coloring} of a simple undirected graph $G=(V,E)$ is a function $c:V\to C$ into a set of colors such that $c(u)\ne c(v)$ whenever $\{u,v\}\in E$. The number of colors used is $|c(V)|$; the chromatic number is the least possible number. The function need not use every available color in $C$.
