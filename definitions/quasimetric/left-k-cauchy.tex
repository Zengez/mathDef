% term: Left K-Cauchy sequence

% source: https://arxiv.org/abs/2511.16503
% arxiv: 2511.16503v1
% locator: Definition 2.7, p. 4
% source_title: Quasi-metric spaces on which real-valued continuous functions are uniformly continuous
% status: draft

A sequence $(x_n)$ is \emph{left $K$-Cauchy} if, for every $\varepsilon>0$, some $N$ satisfies $d(x_k,x_n)<\varepsilon$ whenever $N\le k\le n$.
