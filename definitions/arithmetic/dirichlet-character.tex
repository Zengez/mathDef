For an integer $q\ge1$, a \emph{Dirichlet character modulo $q$} is a function $\chi:\mathbb Z\to\mathbb C$ obtained from a group character $(\mathbb Z/q\mathbb Z)^\times\to\mathbb C^\times$, extended by $0$ on integers not coprime to $q$. Thus it is periodic modulo $q$ and completely multiplicative, with $|\chi(n)|=1$ for $\gcd(n,q)=1$; for $q=1$ the zero-extension clause is vacuous.
