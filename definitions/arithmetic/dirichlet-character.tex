A \emph{Dirichlet character modulo $q$} is a completely multiplicative function $\chi:\mathbb Z\to\mathbb C$ periodic modulo $q$, vanishing when $\gcd(n,q)>1$, with $|\chi(n)|=1$ when $\gcd(n,q)=1$.
