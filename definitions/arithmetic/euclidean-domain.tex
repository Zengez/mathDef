An integral domain $R$ is a \emph{Euclidean domain} if there is a function $\delta:R\setminus\{0\}\to\mathbb N_0$ such that for any $a,b\in R$ with $b\ne0$ there exist $q,r\in R$ satisfying $a=bq+r$ and either $r=0$ or $\delta(r)<\delta(b)$. Such a function is a Euclidean function; every Euclidean domain is a principal ideal domain.
