A domain $R$ is \emph{Euclidean} if some function $\delta:R\setminus\{0\}\to\mathbb N$ satisfies: for $a,b\in R$, $b\ne0$, there exist $q,r$ with $a=bq+r$ and either $r=0$ or $\delta(r)<\delta(b)$.
