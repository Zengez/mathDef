% term: p-adic absolute value

% status: draft

For prime $p$, define $|x|_p=p^{-v_p(x)}$ for $x\in\mathbb Q^\times$ and $|0|_p=0$. It satisfies $|x+y|_p\le\max\{|x|_p,|y|_p\}$.
