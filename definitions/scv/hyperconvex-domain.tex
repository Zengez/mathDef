A bounded domain $\Omega\subseteq\mathbb C^n$ is \emph{hyperconvex} if it has a continuous negative plurisubharmonic function $\rho:\Omega\to(-\infty,0)$ such that $\{\rho<c\}$ is relatively compact in $\Omega$ for every $c<0$. The restriction to negative levels matters: an everywhere negative bounded function cannot have compact sublevel sets for \emph{every} real threshold on a noncompact domain.
