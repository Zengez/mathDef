On a CR manifold $(M,T^{0,1}M)$, a complex-valued $C^1$ function $f$ is a \emph{CR function} if $Lf=0$ for every local smooth vector field $L$ taking values in $T^{0,1}M$. Thus it solves the tangential Cauchy--Riemann equations. On a smooth real hypersurface of a complex manifold, restrictions of ambient holomorphic functions provide examples of CR functions.
