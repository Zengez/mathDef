For a CR manifold $(M,T^{0,1}M)$, a complex-valued $C^1$ function $f$ on $M$ is a \emph{CR function} if $Lf=0$ for every local smooth vector field $L$ taking values in $T^{0,1}M$. On a real hypersurface of $\mathbb C^n$, these are the tangential Cauchy--Riemann equations.
