% term: Defining function for a smooth domain

For a domain $\Omega\subseteq\mathbb C^n$ with $C^2$ boundary, a \emph{local defining function} near $p\in\partial\Omega$ is a real-valued $C^2$ function $\rho$ with $\Omega=\{\rho<0\}$ locally, $\partial\Omega=\{\rho=0\}$ locally, and $d\rho\ne0$ on the local boundary.
