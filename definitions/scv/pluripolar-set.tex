% status: draft

For a domain $\Omega\subseteq\mathbb C^n$, a subset $E\subseteq\Omega$ is \emph{pluripolar relative to $\Omega$} if $E\subseteq\{z\in\Omega:u(z)=-\infty\}$ for some plurisubharmonic $u$ on $\Omega$ not identically $-\infty$. Some treatments begin with a local version of this condition.
