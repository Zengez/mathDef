% term: Pluripolar set (global convention)
% related: scv.plurisubharmonic-function, scv.complete-pluripolar-set
% source: https://en.wikipedia.org/wiki/Pluripolar_set
% status: draft

For a domain $\Omega\subseteq\mathbb C^n$, a subset $E$ is \emph{pluripolar under the global-on-$\Omega$ convention} if $E\subseteq\{u=-\infty\}$ for some plurisubharmonic $u$ on $\Omega$ with $u\not\equiv-\infty$. Other texts start with a local definition, requiring a suitable negative-infinity locus near each point of $E$; this convention should be made explicit.
