% term: Pluricomplex Green function

% status: draft

For a domain $\Omega\subseteq\mathbb C^n$ and $w\in\Omega$, define the \emph{pluricomplex Green function} by the upper-semicontinuous regularization of $\sup\{u(z):u\in\operatorname{PSH}(\Omega),\ u\le0,\ u(\zeta)\le\log\|\zeta-w\|+O(1)\text{ near }w\}$. In dimension one, the sign is opposite to a common convention for the classical Green function.
