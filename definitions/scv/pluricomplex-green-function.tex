% term: Pluricomplex Green function

For a domain $\Omega\subseteq\mathbb C^n$ and $w\in\Omega$, the \emph{pluricomplex Green function with unit logarithmic pole} is the upper-semicontinuous regularization of
\[
g_\Omega(z,w)=\sup\{u(z):u\in\operatorname{PSH}(\Omega),\ u\le0,\ u(\zeta)\le\log\|\zeta-w\|+O(1)\text{ near }w\}.
\]
It is nonpositive; a common convention for the classical one-variable Green function has the opposite sign.
