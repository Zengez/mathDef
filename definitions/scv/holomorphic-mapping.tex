For domains $U\subseteq\mathbb C^n$, $V\subseteq\mathbb C^m$, a map $F=(f_1,\ldots,f_m):U\to V$ is \emph{holomorphic} if each component $f_j:U\to\mathbb C$ is holomorphic.
