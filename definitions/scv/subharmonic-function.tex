% id: scv.subharmonic-function
% term: Subharmonic function on a plane domain
% related: scv.upper-semicontinuous, scv.plurisubharmonic-function
% source: https://en.wikipedia.org/wiki/Subharmonic_function
% status: draft

An upper semicontinuous $u:U\to[-\infty,\infty)$ on a plane domain $U$ is \emph{subharmonic} if for each closed disk $\overline{D(a,r)}\subset U$,
\[
u(a)\le\frac{1}{2\pi}\int_0^{2\pi}u(a+re^{i\theta})\,d\theta.
\]
The identically $-\infty$ function is permitted under this convention.
