An upper semicontinuous function $u:\Omega\to[-\infty,\infty)$ on open $\Omega\subseteq\mathbb C^n$ is \emph{plurisubharmonic} if for every complex affine line $L$, the restriction of $u$ to each component of $\Omega\cap L$ is subharmonic, with the convention that the identically $-\infty$ function is allowed. The condition is local along all nonconstant affine complex lines.
