For a complex manifold $X$ and $p\in X$, an \emph{analytic-set germ at $p$} is an equivalence class of complex analytic subsets $A\subseteq U$ containing $p$, defined on open neighborhoods $U$ of $p$, where two are equivalent if they coincide on a smaller neighborhood of $p$. Equivalently, one may work with the local analytic set defined by a finitely generated proper ideal of holomorphic function germs; distinct ideals can have the same underlying set germ unless the associated radical ideals are used.
