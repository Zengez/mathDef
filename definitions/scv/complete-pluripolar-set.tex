% status: draft

A subset $E$ of a domain $\Omega\subseteq\mathbb C^n$ is \emph{complete pluripolar} if there exists a plurisubharmonic function $u\not\equiv-\infty$ on $\Omega$ such that $E=\{z\in\Omega:u(z)=-\infty\}$.
