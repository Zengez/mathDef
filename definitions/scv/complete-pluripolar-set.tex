A subset $E$ of a domain $\Omega\subseteq\mathbb C^n$ is \emph{complete pluripolar relative to $\Omega$} if there exists a plurisubharmonic $u\not\equiv-\infty$ on $\Omega$ with
\[
E=\{z\in\Omega:u(z)=-\infty\}.
\]
An arbitrary pluripolar set is only required to be contained in such a locus. The property depends on the ambient domain.
