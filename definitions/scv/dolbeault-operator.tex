For an open set $\Omega\subseteq\mathbb C^n$ and a $C^1$ function $f$, the \emph{Dolbeault operator} on functions is the $(0,1)$-form
\[
\bar\partial f=\sum_{j=1}^n\frac{\partial f}{\partial\bar z_j}\,d\bar z_j,
\quad\frac{\partial}{\partial\bar z_j}=\frac12\left(\frac{\partial}{\partial x_j}+i\frac{\partial}{\partial y_j}\right).
\]
