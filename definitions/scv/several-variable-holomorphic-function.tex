% term: Holomorphic function of several complex variables

% status: draft

A function $f:\Omega\to\mathbb C$ on open $\Omega\subseteq\mathbb C^n$ is \emph{holomorphic} if, near each point of $\Omega$, it has a convergent power-series expansion in the $n$ complex coordinates. Equivalently, it is separately holomorphic in each complex coordinate.
