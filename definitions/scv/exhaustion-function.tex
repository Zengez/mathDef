% term: Exhaustion function on a topological space
% related: scv.pseudoconvex-domain, topology.locally-compact

% status: draft

A continuous function $\rho:X\to\mathbb R$ on a locally compact Hausdorff space is an \emph{exhaustion function} if each sublevel set $\{x:\rho(x)\le c\}$ is compact for every real $c$. For continuous $\rho$ that is bounded below, this is equivalent to properness as a map $X\to\mathbb R$; without the lower bound, properness alone is not sufficient.
