% id: scv.exhaustion-function
% term: Exhaustion function on a topological space
% related: scv.pseudoconvex-domain, topology.locally-compact
% source: https://en.wikipedia.org/wiki/Exhaustion_function
% status: draft

A continuous function $\rho:X\to\mathbb R$ on a locally compact Hausdorff space is an \emph{exhaustion function} if each sublevel set $\{x:\rho(x)\le c\}$ is compact for every real $c$. Equivalently, $\rho$ is a proper map to $\mathbb R$ when the function is bounded below.
