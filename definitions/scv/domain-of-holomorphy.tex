A domain $\Omega\subseteq\mathbb C^n$ is a \emph{domain of holomorphy} if some $f\in\mathcal O(\Omega)$ admits no holomorphic extension to any strictly larger domain containing $\Omega$. This is equivalent to pseudoconvexity, by the Levi problem.
