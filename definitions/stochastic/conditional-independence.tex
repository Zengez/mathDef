% id: stochastic.conditional-independence
% term: Conditional independence of events
% related: prob.independence, prob.conditional-probability
% source: https://en.wikipedia.org/wiki/Conditional_independence
% status: draft

For events $A,B,C$ with $P(C)>0$, $A$ and $B$ are \emph{conditionally independent given the event $C$} if $P(A\cap B\mid C)=P(A\mid C)P(B\mid C)$.
