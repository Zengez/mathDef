% id: stochastic.conditional-independence
% term: Conditional independence of events
% related: prob.independence, prob.conditional-probability
% source: https://encyclopediaofmath.org/wiki/Martingale
% status: draft

Events $A,B$ are \emph{conditionally independent given $C$}, with $P(C)>0$, if $P(A\cap B\mid C)=P(A\mid C)P(B\mid C)$.
