% id: stochastic.strong-markov-property
% term: Strong Markov property
% related: prob.markov-chain, stochastic.stopping-time
% source: https://encyclopediaofmath.org/wiki/Martingale
% status: draft

An adapted Markov process is \emph{strong Markov} if its conditional future evolution following each finite stopping time depends on the past only through the state at that stopping time, with the same transition semigroup.
