% id: stochastic.strong-markov-property
% term: Strong Markov property
% related: prob.markov-chain, stochastic.stopping-time
% source: https://encyclopediaofmath.org/wiki/Markov_process
% status: draft

A time-homogeneous Markov process $X$ adapted to $(\mathcal F_t)$, with transition semigroup $(P_t)$, has the \emph{strong Markov property} if for every almost-surely finite stopping time $\tau$, every $t\ge0$, and every bounded measurable function $f$, one has $E[f(X_{\tau+t})\mid\mathcal F_\tau]=(P_t f)(X_\tau)$ almost surely.
