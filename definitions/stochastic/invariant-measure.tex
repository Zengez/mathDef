% id: stochastic.invariant-measure
% term: Invariant probability measure
% related: measure.probability-measure, stochastic.ergodic-measure
% source: https://encyclopediaofmath.org/wiki/Martingale
% status: draft

A probability measure $\mu$ on a measurable space is \emph{invariant} for measurable $T:X\to X$ if $\mu(T^{-1}A)=\mu(A)$ for every measurable set $A$.
