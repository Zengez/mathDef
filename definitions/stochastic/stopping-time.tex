% id: stochastic.stopping-time
% term: Stopping time
% related: stochastic.filtration, stochastic.stopped-process
% source: https://encyclopediaofmath.org/wiki/Martingale
% status: draft

A random time $\tau:\Omega\to\mathbb N_0\cup\{\infty\}$ is a \emph{stopping time} for filtration $(\mathcal F_n)$ if $\{\tau\le n\}\in\mathcal F_n$ for each $n$.
