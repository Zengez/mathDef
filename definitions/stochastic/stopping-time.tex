% term: Stopping time
% related: stochastic.filtration, stochastic.stopped-process

% status: draft

A random time $\tau:\Omega\to\mathbb N_0\cup\{\infty\}$ is a \emph{stopping time} with respect to a filtration $(\mathcal F_n)_{n\ge0}$ if $\{\tau\le n\}\in\mathcal F_n$ for each $n$.
