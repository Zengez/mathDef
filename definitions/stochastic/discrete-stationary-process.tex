% status: draft

A process $(X_t)$ is \emph{strictly stationary} if for every finite time list $(t_1,\ldots,t_n)$ and every shift $h$ for which the shifted times lie in the index set the joint distributions of $(X_{t_1+h},\ldots,X_{t_n+h})$ and $(X_{t_1},\ldots,X_{t_n})$ agree.
