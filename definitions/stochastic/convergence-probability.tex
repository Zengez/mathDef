% id: stochastic.convergence-probability
% term: Convergence in probability
% related: prob.random-variable, stochastic.almost-sure-convergence

% status: draft

Random variables $X_n$ \emph{converge in probability} to $X$ if $P(|X_n-X|>\varepsilon)\to0$ for every $\varepsilon>0$.
