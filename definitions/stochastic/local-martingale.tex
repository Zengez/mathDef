% term: Local martingale
% related: stochastic.martingale, stochastic.stopping-time
% source: https://en.wikipedia.org/wiki/Local_martingale
% status: draft

An adapted càdlàg real process $(M_t)_{t\ge0}$ is a \emph{local martingale} if there are stopping times $\tau_n\uparrow\infty$ almost surely such that each stopped process $(M_{t\wedge\tau_n})_{t\ge0}$ is a martingale.
