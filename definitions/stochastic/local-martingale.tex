An adapted càdlàg real-valued process $(M_t)_{t\ge0}$ is a \emph{local martingale} if there are stopping times $\tau_n\uparrow\infty$ almost surely such that every stopped process $M^{\tau_n}=(M_{t\wedge\tau_n})_{t\ge0}$ is an integrable martingale with respect to the given filtration: for all $0\le s\le t$,
\[
E[M_{t\wedge\tau_n}\mid\mathcal F_s]=M_{s\wedge\tau_n}\quad\text{almost surely}.
\]
Such $(\tau_n)$ is called a \emph{localizing sequence}. This is the continuous-time counterpart of the discrete-time martingale condition.
