% id: stochastic.ergodic-measure
% term: Ergodic invariant probability measure
% related: stochastic.invariant-measure, dynamics.invariant-set
% source: https://encyclopediaofmath.org/wiki/Martingale
% status: draft

For measurable $T:X\to X$, a $T$-invariant probability measure $\mu$ is \emph{ergodic} if every measurable set $A$ with $T^{-1}A=A$ modulo null sets has measure $0$ or $1$.
