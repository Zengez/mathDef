% term: Covariance function of a process
% related: prob.covariance, stochastic.gaussian-process
% source: https://encyclopediaofmath.org/wiki/Martingale
% status: draft

For a square-integrable process $(X_t)$, its \emph{covariance function} is $K(s,t)=E[(X_s-E[X_s])(X_t-E[X_t])]$.
