% id: stochastic.martingale
% term: Discrete-time martingale
% related: stochastic.filtration, stochastic.submartingale
% source: https://encyclopediaofmath.org/wiki/Martingale
% status: draft

An integrable adapted sequence $(M_n)$ is a \emph{martingale} if $E[M_{n+1}\mid\mathcal F_n]=M_n$ almost surely for all $n$.
