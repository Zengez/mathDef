% term: Essential supremum
% related: measure.almost-everywhere, measure.measure
% source: https://encyclopediaofmath.org/wiki/Martingale
% status: draft

The \emph{essential supremum} of a measurable real function $f$ is $\operatorname*{ess\,sup}f=\inf\{M\in\mathbb R:f\le M\text{ almost everywhere}\}$, allowing infinite values.
