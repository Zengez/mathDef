% status: draft

For a measurable real-valued function $f$ on a measure space $(X,\mathcal F,\mu)$, its \emph{essential supremum} is $\operatorname*{ess\,sup}f=\inf\{M\in\mathbb R:f\le M\text{ almost everywhere}\}$, with the infimum interpreted in the extended real line (including $+\infty$ if no finite bound exists).
