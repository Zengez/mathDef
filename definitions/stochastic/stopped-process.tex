% id: stochastic.stopped-process
% term: Stopped process
% related: stochastic.stopping-time, stochastic.martingale
% source: https://en.wikipedia.org/wiki/Stopping_time
% status: draft

For a discrete-time process $(X_n)_{n\ge0}$ and a stopping time $\tau$ with values in $\mathbb N_0\cup\{\infty\}$, the \emph{stopped process} is $X_n^\tau=X_{n\wedge\tau}$. On paths with $\tau=\infty$, the stopped process agrees with $X_n$ at every finite time.
