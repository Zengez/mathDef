% term: Renewal process
% related: prob.iid, stochastic.poisson-process

% status: draft

For i.i.d. strictly positive waiting times $(W_n)$ with $S_n=\sum_{k=1}^nW_k$, the \emph{renewal counting process} is $N(t)=\max\{n:S_n\le t\}$, when this is finite almost surely.
