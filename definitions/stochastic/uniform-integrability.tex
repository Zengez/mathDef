% id: stochastic.uniform-integrability
% term: Uniform integrability
% related: prob.expectation, stochastic.convergence-lp
% source: https://en.wikipedia.org/wiki/Uniform_integrability
% status: draft

A family $\mathcal X$ of integrable real random variables is \emph{uniformly integrable} if $\lim_{K\to\infty}\sup_{X\in\mathcal X}E[|X|\mathbf1_{\{|X|>K\}}]=0$.
