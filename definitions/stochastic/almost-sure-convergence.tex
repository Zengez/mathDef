% id: stochastic.almost-sure-convergence
% term: Almost sure convergence
% related: prob.almost-surely, stochastic.convergence-probability
% source: https://encyclopediaofmath.org/wiki/Martingale
% status: draft

Random variables $X_n$ \emph{converge almost surely} to $X$ if $P(\{\omega:X_n(\omega)\to X(\omega)\})=1$.
