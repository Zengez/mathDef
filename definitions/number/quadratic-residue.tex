Given an integer $n\ge1$, a \emph{quadratic residue modulo $n$} is a residue class $[a]_n\in\mathbb Z/n\mathbb Z$ for which $x^2\equiv a\pmod n$ has an integer solution $x$. In this convention $[0]_n$ is a quadratic residue. In multiplicative-group contexts the term is sometimes restricted to classes coprime to $n$.
