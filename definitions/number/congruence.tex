% id: number.congruence
% term: Congruence modulo an integer
% related: number.divisibility, number.modular-arithmetic
% source: https://en.wikipedia.org/wiki/Modular_arithmetic
% status: draft

For integers $a,b$ and a positive integer modulus $n$, the congruence $a\equiv b\pmod n$ means $n\mid(a-b)$, equivalently $a-b=kn$ for some $k\in\mathbb Z$. This is an equivalence relation on $\mathbb Z$ whose classes form $\mathbb Z/n\mathbb Z$.
