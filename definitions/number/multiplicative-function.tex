An arithmetic function $f:\mathbb Z_{>0}\to\mathbb C$ is \emph{multiplicative} if $f(1)=1$ and $f(mn)=f(m)f(n)$ whenever $\gcd(m,n)=1$. A \emph{completely multiplicative} function satisfies the product identity for all positive integers $m,n$, not just coprime inputs.
