For a positive integer $n$ and an integer $a$, the \emph{residue class of $a$ modulo $n$} is $[a]_n=\{a+kn:k\in\mathbb Z\}$. Equivalently, it contains exactly the integers congruent to $a$ modulo $n$. The set of all distinct classes is denoted $\mathbb Z/n\mathbb Z$ and has $n$ elements.
