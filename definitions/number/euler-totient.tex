For an integer $n\ge1$, Euler's \emph{totient function} is $\varphi(n)=\#\{k\in\{1,\ldots,n\}:\gcd(k,n)=1\}$. In particular $\varphi(1)=1$. For $n>1$, the totient counts invertible residue classes modulo $n$; it is multiplicative for coprime inputs.
