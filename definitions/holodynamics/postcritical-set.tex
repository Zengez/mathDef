% id: holodynamics.postcritical-set
% term: Postcritical set
% related: holodynamics.critical-point, holodynamics.critical-value
% source: https://www.math.univ-toulouse.fr/~buff/Preprints/Teichmuller/Teichmuller.pdf
% status: draft

For a rational map $R:\widehat{\mathbb C}\to\widehat{\mathbb C}$, its \emph{postcritical set} is
\[
P(R)=\overline{\bigcup_{n\ge1}R^n(\operatorname{Crit}(R))}
\]
where the closure and all images are taken on the Riemann sphere. Thus it is the closure of the forward orbits of all critical values. Some authors use the unclosed forward union and reserve \emph{postcritical closure} for $P(R)$; the convention must be stated.
