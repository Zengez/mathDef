% term: Escaping set of a polynomial
% related: holodynamics.filled-julia-set, holodynamics.iterate
% source: https://encyclopediaofmath.org/wiki/Julia_set
% status: draft

For a polynomial $p$ of degree at least $2$, its \emph{escaping set} is $I(p)=\{z\in\mathbb C:|p^n(z)|\to\infty\}$.
