% term: Escaping set of a polynomial

% status: draft

For a complex polynomial $p$ of degree at least two, its \emph{escaping set} is
\[
I(p)=\{z\in\mathbb C:|p^n(z)|\to\infty\text{ as }n\to\infty\}.
\]
For such a polynomial every forward orbit that is not bounded escapes to infinity, so $I(p)=\mathbb C\setminus K(p)$, where $K(p)$ is the filled Julia set. Escape takes place in the affine complex plane, although infinity is a superattracting fixed point on the sphere.
