% term: Fatou set of a rational map
% related: holodynamics.normal-family, holodynamics.julia-set

% status: draft

For a rational map $R$ of degree at least two, the \emph{Fatou set} $F(R)$ consists of points $z\in\widehat{\mathbb C}$ admitting a neighborhood $U$ on which the family of iterates $\{R^n|_U:n\ge0\}$ is normal in the spherical metric. It is an open completely invariant subset of the Riemann sphere. Its complement is the Julia set $J(R)$.
