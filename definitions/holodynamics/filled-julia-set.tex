% id: holodynamics.filled-julia-set
% term: Filled Julia set of a polynomial
% related: holodynamics.julia-set, holodynamics.iterate
% source: https://encyclopediaofmath.org/wiki/Julia_set
% status: draft

For a complex polynomial $p$ of degree at least $2$, its \emph{filled Julia set} is $K(p)=\{z\in\mathbb C:\sup_{n\ge0}|p^n(z)|<\infty\}$.
