A \emph{critical value} of a nonconstant holomorphic map $f:X\to Y$ between Riemann surfaces is a point $v=f(c)\in Y$ for some critical point $c\in X$. Distinct critical points can have the same critical value. In rational dynamics, both critical points and their forward images are taken on the Riemann sphere, so the value $\infty$ is permitted.
