For a rational map $R:\widehat{\mathbb C}\to\widehat{\mathbb C}$ of degree at least two, a \emph{Fatou component} is a connected component of its Fatou set $F(R)$. It is an open connected subset of the sphere. Iteration maps each Fatou component into another Fatou component, which makes it meaningful to distinguish periodic, preperiodic and wandering components.
