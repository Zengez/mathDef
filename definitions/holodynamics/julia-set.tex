% id: holodynamics.julia-set
% term: Julia set of a rational map
% related: holodynamics.fatou-set, holodynamics.rational-map
% source: https://encyclopediaofmath.org/wiki/Julia_set
% status: draft

For a rational map $R$ of degree at least $2$, the \emph{Julia set} is $J(R)=\widehat{\mathbb C}\setminus F(R)$, the complement of the Fatou set.
