For an optimization problem minimizing an extended-real-valued function $f$ over a feasible set $C$, its \emph{optimal value} is $p^*=\inf_{x\in C}f(x)$, whether or not the infimum is attained. In the extended-real convention $\inf\varnothing=+\infty$; unbounded-below problems have $p^*=-\infty$. The analogous maximization value is a supremum.
