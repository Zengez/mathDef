% id: optimization.positive-semidefinite
% term: Positive semidefinite matrix
% related: linear.matrix, optimization.semidefinite-program
% source: https://web.stanford.edu/~boyd/cvxbook/
% status: draft

A real symmetric matrix $A$ is \emph{positive semidefinite} if $x^{\mathsf T}Ax\ge0$ for every $x\in\mathbb R^n$.
