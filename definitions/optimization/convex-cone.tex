% status: draft

A \emph{convex cone} in a real vector space is a nonempty set $K$ such that $\alpha x+\beta y\in K$ whenever $x,y\in K$ and $\alpha,\beta\ge0$. In particular, $0\in K$ under this convention. Some authors allow the empty cone, so the nonemptiness requirement may vary.
