% status: draft

A map $f:\mathbb R^n\to\mathbb R^m$ is \emph{affine} if there is a linear map $A:\mathbb R^n\to\mathbb R^m$ and a vector $b\in\mathbb R^m$ such that $f(x)=Ax+b$ for all $x$. Equivalently, it preserves affine combinations: $f((1-t)x+ty)=(1-t)f(x)+tf(y)$ for all real $t$.
