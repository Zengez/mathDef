% id: optimization.quasiconvex-function
% term: Quasiconvex function
% related: optimization.sublevel-set, real.convex-function
% source: https://web.stanford.edu/~boyd/cvxbook/
% status: draft

A function $f$ on a convex domain is \emph{quasiconvex} if each sublevel set $\{x:f(x)\le\alpha\}$ is convex.
