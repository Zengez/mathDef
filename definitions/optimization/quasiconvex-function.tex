% status: draft

A real-valued function $f:C\to\mathbb R$ on a convex set $C$ is \emph{quasiconvex} if every sublevel set $\{x\in C:f(x)\le a\}$ is convex for $a\in\mathbb R$. Equivalently, for every $x,y\in C$ and $t\in[0,1]$,
\[
f((1-t)x+ty)\le\max\{f(x),f(y)\}.
\]
Every convex function is quasiconvex, but not conversely.
