For a minimization problem $\inf_{x\in C}f(x)$ with feasible set $C$, an \emph{optimal solution} is a feasible point $x^*\in C$ satisfying $f(x^*)\le f(x)$ for every $x\in C$. Equivalently, it attains the infimum. A finite optimal value need not be attained, so an optimal solution need not exist even when $C$ is nonempty.
