% id: optimization.strong-convexity
% term: Strong convexity
% related: real.convex-function, optimization.strict-convexity
% source: https://web.stanford.edu/~boyd/cvxbook/
% status: draft

A function $f$ on a convex subset of $\mathbb R^n$ is \emph{$m$-strongly convex} for $m>0$ if $x\mapsto f(x)-\frac m2\|x\|^2$ is convex.
