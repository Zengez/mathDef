% id: optimization.duality-gap
% term: Duality gap
% related: optimization.dual-problem, optimization.strong-duality
% source: https://web.stanford.edu/~boyd/cvxbook/
% status: draft

For a minimization problem with primal optimum $p^*$ and dual optimum $d^*$, the \emph{duality gap} is $p^*-d^*\ge0$ when both are finite.
