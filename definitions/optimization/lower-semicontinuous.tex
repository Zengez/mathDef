% id: optimization.lower-semicontinuous
% term: Lower semicontinuity
% related: topology.open-set, optimization.epigraph
% source: https://web.stanford.edu/~boyd/cvxbook/
% status: draft

A function $f:X\to(-\infty,\infty]$ on a topological space is \emph{lower semicontinuous} if $\{x:f(x)>\alpha\}$ is open for each real $\alpha$.
