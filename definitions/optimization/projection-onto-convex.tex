% id: optimization.projection-onto-convex
% term: Euclidean projection onto a convex set
% related: real.convex-set, optimization.proximal-operator
% source: https://web.stanford.edu/~boyd/cvxbook/
% status: draft

For a nonempty closed convex set $C\subseteq\mathbb R^n$, the \emph{Euclidean projection} $P_C(x)$ is the unique minimizer of $\|x-y\|$ over $y\in C$.
