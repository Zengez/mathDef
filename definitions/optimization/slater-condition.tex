% id: optimization.slater-condition
% term: Slater condition
% related: optimization.convex-optimization, optimization.strong-duality
% source: https://web.stanford.edu/~boyd/cvxbook/
% status: draft

For a convex program with affine equalities and convex inequalities $f_i(x)\le0$, a \emph{strictly feasible point} satisfies the equalities and all nonaffine inequalities strictly; this is the usual Slater constraint qualification (with domain conditions).
