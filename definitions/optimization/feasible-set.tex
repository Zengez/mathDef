The \emph{feasible set} of a constrained optimization problem is the set $C$ of candidate decision variables that satisfy all prescribed constraints. A point $x\in C$ is feasible; a point minimizing the objective over $C$ is optimal if such a point exists. The feasible set may be empty or nonconvex in general.
