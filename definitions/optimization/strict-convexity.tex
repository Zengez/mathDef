% id: optimization.strict-convexity
% term: Strictly convex function
% related: real.convex-function, optimization.strong-convexity
% source: https://web.stanford.edu/~boyd/cvxbook/
% status: draft

A function $f$ on a convex set is \emph{strictly convex} if $f((1-t)x+ty)<(1-t)f(x)+tf(y)$ for all distinct $x,y$ and $0<t<1$.
