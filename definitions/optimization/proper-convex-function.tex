% id: optimization.proper-convex-function
% term: Proper convex function
% related: real.convex-function, optimization.convex-conjugate
% source: https://web.stanford.edu/~boyd/cvxbook/
% status: draft

An extended-real-valued convex function $f:\mathbb R^n\to(-\infty,\infty]$ is \emph{proper} if its effective domain is nonempty and it never takes the value $-\infty$.
