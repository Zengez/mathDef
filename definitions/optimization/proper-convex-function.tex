% status: draft

An extended-real-valued convex function $f:\mathbb R^n\to[-\infty,+\infty]$ is \emph{proper} if $f(x)>-\infty$ for every $x$ and its effective domain $\operatorname{dom}f=\{x:f(x)<+\infty\}$ is nonempty. Equivalently, it is never $-\infty$ and is not identically $+\infty$. Properness does not by itself imply lower semicontinuity.
