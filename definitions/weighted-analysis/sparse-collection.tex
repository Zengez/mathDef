% status: draft

A family $\mathcal S$ is \emph{$1/\tau$-sparse}, $\tau\ge1$, if each $Q\in\mathcal S$ contains a measurable $E_Q$ with the $E_Q$ pairwise disjoint and $|E_Q|\ge|Q|/\tau$.
