For $1<p<\infty$ and positive weights $w,\sigma$ on $\mathbb B_d$, set $[w,\sigma]_{B_p}=\sup_{z\in\mathbb B_d}\langle w\rangle_{T_z}\langle\sigma\rangle_{T_z}^{p-1}$, using volume averages. A weight $w$ belongs to $B_p$ when $[w,w^{1-p'}]_{B_p}<\infty$.
