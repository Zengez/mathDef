% id: measure.completion-of-measure
% term: Completion of a measure space
% related: measure.measurable-space, measure.null-set
% source: https://en.wikipedia.org/wiki/Complete_measure
% status: draft

For a measure space $(X,\Sigma,\mu)$, the \emph{completion} adds every subset of every measurable null set. Concretely, let
\[
\overline\Sigma=\{A\cup N:A\in\Sigma,\ N\subseteq Z\in\Sigma,\ \mu(Z)=0\},
\]
and set $\overline\mu(A\cup N)=\mu(A)$. This prescription is well-defined and defines the smallest complete extension of $\mu$ on the same underlying set.
