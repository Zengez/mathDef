An \emph{outer measure} on a set $X$ is a function $\mu^*:\mathcal P(X)\to[0,\infty]$ satisfying $\mu^*(\varnothing)=0$, monotonicity $A\subseteq B\Rightarrow\mu^*(A)\le\mu^*(B)$, and countable subadditivity
\[
\mu^*\left(\bigcup_{n=1}^\infty A_n\right)\le\sum_{n=1}^\infty\mu^*(A_n)
\]
for arbitrary subsets $A_n\subseteq X$. Countable \emph{additivity} is not assumed on all subsets.
