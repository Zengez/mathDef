% term: Pettis integrable function
% related: functional.continuous-dual, measure.bochner-integrable
% source: https://en.wikipedia.org/wiki/Pettis_integral
% status: draft

Let $(X,\Sigma,\mu)$ be a measure space and $B$ a Banach space. A function $f:X\to B$ is \emph{Pettis integrable} if each scalar function $\varphi\circ f$ for $\varphi\in B^*$ is Lebesgue integrable and, for every $A\in\Sigma$, there exists $I_A\in B$ such that
\[
\varphi(I_A)=\int_A\varphi(f)\,d\mu\quad\text{for every }\varphi\in B^*.
\]
Such $I_A$ is unique. Bochner integrability implies Pettis integrability, but the converse can fail.
