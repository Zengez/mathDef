% id: measure.pettis-integrable
% term: Pettis integrable function
% related: functional.continuous-dual, measure.bochner-integrable
% source: https://en.wikipedia.org/wiki/Pettis_integral
% status: draft

A function $f:X\to B$ to a Banach space is \emph{Pettis integrable} if every $\varphi\circ f$, $\varphi\in B'$, is integrable and, for each measurable $A\subseteq X$, some $I_A\in B$ satisfies $\varphi(I_A)=\int_A\varphi(f)\,d\mu$ for every $\varphi\in B'$.
