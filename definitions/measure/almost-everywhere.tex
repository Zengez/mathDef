% status: draft

Given a measure space $(X,\Sigma,\mu)$, a property $P(x)$ holds \emph{$\mu$-almost everywhere} if there exists a measurable set $N\in\Sigma$ with $\mu(N)=0$ such that $P(x)$ holds for every $x\in X\setminus N$. The set where the property fails need not itself be measurable, as long as it is contained in a measurable null set.
