% term: Atom of a measure
% related: measure.measure, measure.null-set
% source: https://en.wikipedia.org/wiki/Atom_%28measure_theory%29
% status: draft

A measurable set $A$ is an \emph{atom} of a positive measure $\mu$ if $\mu(A)>0$ and for every measurable $B\subseteq A$ either $\mu(B)=0$ or $\mu(B)=\mu(A)$.
