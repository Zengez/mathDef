% term: Atom of a measure
% related: measure.measure, measure.null-set

% status: draft

For a positive measure $\mu$ on $(X,\Sigma)$, an \emph{atom} is a measurable set $A\in\Sigma$ with $\mu(A)>0$ such that each measurable $B\subseteq A$ satisfies either $\mu(B)=0$ or $\mu(B)=\mu(A)$. The set $A$ need not be a singleton and the definition allows $\mu(A)=\infty$ unless a finite-measure hypothesis is imposed.
