% id: measure.outer-regular
% term: Outer regular Borel measure
% related: measure.borel-sigma-algebra, measure.radon-measure
% source: https://en.wikipedia.org/wiki/Radon_measure
% status: draft

A Borel measure $\mu$ on $X$ is \emph{outer regular} if $\mu(A)=\inf\{\mu(U):A\subseteq U,\ U\text{ open}\}$ for every Borel set $A$.
