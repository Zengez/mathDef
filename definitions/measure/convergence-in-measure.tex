Measurable real-valued functions $f_n,f$ on a measure space $(X,\Sigma,\mu)$ satisfy \emph{global convergence in measure}, written $f_n\to f$ in $\mu$-measure, if for every $\varepsilon>0$,
\[
\mu\bigl(\{x:|f_n(x)-f(x)|>\varepsilon\}\bigr)\longrightarrow0.
\]
On infinite-measure spaces this is generally stronger than \emph{local convergence in measure}, which requires the same limit after intersecting the set with every measurable set of finite measure.
