For a measure space $(X,\Sigma,\mu)$, a \emph{measurable null set} is $N\in\Sigma$ with $\mu(N)=0$. In a non-complete measure space, a subset of a measurable null set need not itself be measurable. The phrase \emph{null set} is sometimes extended to arbitrary subsets of measurable sets of measure zero, so the convention matters.
