For a signed measure $\nu$ on $(X,\Sigma)$, a \emph{Hahn decomposition} is a measurable partition $X=P\sqcup N$ such that $\nu(E)\ge0$ for every measurable $E\subseteq P$ and $\nu(E)\le0$ for every measurable $E\subseteq N$. Such a partition exists for any signed measure in the usual sense, and any two Hahn decompositions differ only on sets null with respect to the total variation $|\nu|$.
