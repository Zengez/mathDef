% term: Positive set for a signed measure

% status: draft

For a signed measure $\nu$ on $(X,\Sigma)$, a measurable set $P$ is \emph{positive} if $\nu(E)\ge0$ for every measurable subset $E\subseteq P$. This condition is stronger than $\nu(P)\ge0$ alone. A Hahn decomposition partitions the space into a positive set and a negative set.
