% term: Positive set for a signed measure
% related: measure.signed-measure, measure.hahn-decomposition
% source: https://en.wikipedia.org/wiki/Hahn_decomposition_theorem
% status: draft

For a signed measure $\nu$, a measurable $P$ is \emph{positive} if $\nu(E)\ge0$ for every measurable $E\subseteq P$. It is not enough to require $\nu(P)\ge0$.
