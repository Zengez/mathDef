% id: measure.strong-measurability
% term: Strong measurability of a Banach-valued function
% related: measure.measurable-function, measure.bochner-integrable
% source: https://en.wikipedia.org/wiki/Bochner_integral
% status: draft

For a measure space $(X,\Sigma,\mu)$ and a Banach space $B$, a function $f:X\to B$ is \emph{strongly measurable} in the Bochner sense if it is a pointwise $\mu$-almost-everywhere limit of measurable $B$-valued simple functions. By the Pettis measurability theorem, for the usual completed-measure convention this is equivalent to weak measurability together with essential separability of the range.
