% term: Negative set for a signed measure

% status: draft

For a signed measure $\nu$ on $(X,\Sigma)$, a measurable set $N\in\Sigma$ is \emph{negative} if $\nu(E)\le0$ for every measurable $E\subseteq N$. Requiring only $\nu(N)\le0$ is insufficient, because positive and negative contributions might cancel. In a Hahn decomposition, the negative part is a negative set in this stronger sense.
