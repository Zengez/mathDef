% term: Negative set for a signed measure

% source: https://en.wikipedia.org/wiki/Hahn_decomposition_theorem
% status: draft

For a signed measure $\nu$, a measurable $N$ is \emph{negative} if $\nu(E)\le0$ for every measurable $E\subseteq N$.
