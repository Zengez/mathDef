In axiomatic set theory such as ZFC, a \emph{set} is a primitive mathematical object; membership $x\in A$ is a primitive relation governed by axioms, including extensionality. An arbitrary collection specified by a property need not itself be a set: unrestricted comprehension is not an axiom of ZFC.
