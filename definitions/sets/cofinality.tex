% term: Cofinality of an ordinal
% related: sets.limit-ordinal, sets.ordinal
% source: https://en.wikipedia.org/wiki/Cofinality
% status: draft

For an ordinal $\alpha$, a subset $C\subseteq\alpha$ is \emph{cofinal} if for each $\beta<\alpha$ there is $\gamma\in C$ with $\beta\le\gamma$. The \emph{cofinality} $\operatorname{cf}(\alpha)$ is the least order type of a cofinal subset. For successor ordinals it is $1$, and $\operatorname{cf}(0)=0$; a nonzero limit ordinal has infinite cofinality.
