A set $A$ is \emph{infinite} if it is not finite: there is no $n\in\mathbb N_0$ and bijection $A\to\{0,\ldots,n-1\}$. In ZFC every infinite set contains a countably infinite subset, but without a choice principle this further property need not follow from infinitude.
