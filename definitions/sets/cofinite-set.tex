% term: Cofinite subset
% related: sets.complement, sets.finite-set
% source: https://en.wikipedia.org/wiki/Cofinite_set
% status: draft

A subset $A$ of a specified set $X$ is \emph{cofinite in $X$} if its relative complement $X\setminus A$ is finite. The ambient set matters: the same subset may be cofinite in one space but not another. The definition applies even when $X$ itself is finite.
