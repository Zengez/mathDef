% term: Countably infinite set
% related: logic.countable-set, sets.infinite-set

% status: draft

A set $A$ is \emph{countably infinite} if a bijection from $\mathbb N$ onto $A$ exists, equivalently if $|A|=\aleph_0$. The phrase \emph{at most countable} includes finite sets; countably infinite excludes them.
