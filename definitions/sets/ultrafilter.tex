% term: Ultrafilter on a set

% status: draft

An \emph{ultrafilter} on a nonempty set $X$ is a maximal proper filter $\mathcal U\subseteq\mathcal P(X)$ under inclusion. Equivalently, for every $A\subseteq X$, exactly one of $A$ and $X\setminus A$ belongs to $\mathcal U$. An ultrafilter is \emph{principal} at $x\in X$ if $\mathcal U=\{A\subseteq X:x\in A\}$; otherwise it is nonprincipal.
