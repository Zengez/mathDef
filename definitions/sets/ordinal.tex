A \emph{von Neumann ordinal} is a transitive set $\alpha$ such that the membership relation $\in$ well-orders $\alpha$. Its elements are exactly the ordinals smaller than $\alpha$, and $\beta<\alpha$ means $\beta\in\alpha$. This representation identifies an ordinal with the set of all preceding ordinals.
