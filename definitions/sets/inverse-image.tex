% term: Inverse image of a subset
% related: sets.relation-image, functions.function
% source: https://en.wikipedia.org/wiki/Inverse_image
% status: draft

For a function $f:X\to Y$ and a subset $B\subseteq Y$, the \emph{inverse image} (preimage) is $f^{-1}[B]=\{x\in X:f(x)\in B\}$. It is defined whether or not $f$ is invertible and satisfies $f^{-1}[B\cup C]=f^{-1}[B]\cup f^{-1}[C]$.
