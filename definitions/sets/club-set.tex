% id: sets.club-set
% term: Closed unbounded (club) subset
% related: sets.cofinality, sets.stationary-set
% source: https://en.wikipedia.org/wiki/Club_set
% status: draft

Let $\kappa$ be an uncountable regular cardinal. A set $C\subseteq\kappa$ is \emph{closed unbounded}, or \emph{club}, if it is unbounded in the ordinal $\kappa$ and closed under nonzero limit points below $\kappa$. Explicitly, for every $\alpha<\kappa$ some $\beta\in C$ satisfies $\alpha<\beta$, and whenever $0<\lambda<\kappa$ is a limit ordinal with $\sup(C\cap\lambda)=\lambda$, one has $\lambda\in C$.
