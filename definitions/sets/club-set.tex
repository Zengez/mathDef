% id: sets.club-set
% term: Closed unbounded (club) subset
% related: sets.cofinality, sets.stationary-set
% source: https://en.wikipedia.org/wiki/Club_set
% status: draft

Let $\kappa$ be an uncountable regular cardinal. A subset $C\subseteq\kappa$ is \emph{closed unbounded} (\emph{club}) if it is unbounded in $\kappa$ and closed in its order topology. Explicitly, for every $\alpha<\kappa$ some $\beta\in C$ satisfies $\alpha<\beta$; and for every nonzero limit ordinal $\lambda<\kappa$, $\sup(C\cap\lambda)=\lambda$ implies $\lambda\in C$.
