For a set $\mathcal A$ whose members are nonempty sets, a \emph{choice function} is a map $c:\mathcal A\to\bigcup\mathcal A$ satisfying $c(A)\in A$ for each $A\in\mathcal A$. The axiom of choice asserts that every set of nonempty sets admits such a function; an individual family's choice function need not require the full axiom.
