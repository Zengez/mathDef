A \emph{forcing notion} is a nonempty partially ordered set $(\mathbb P,\le)$ whose elements are conditions. In the convention used here, $p\le q$ means that $p$ is a \emph{stronger} condition than $q$ (it carries at least as much information). Conditions $p,q$ are \emph{compatible} if some $r$ satisfies $r\le p$ and $r\le q$. Some authors reverse this order or allow preorders instead of partial orders.
