A \emph{forcing notion} in set theory is commonly specified by a nonempty partially ordered set $(\mathbb P,\le)$ of \emph{conditions}, using the convention that $p\le q$ means $p$ provides at least as much information as $q$ (is \emph{stronger}). Two conditions are compatible if they have a common stronger condition. Some presentations use a preorder, adjoin a greatest element, or reverse the order convention.
