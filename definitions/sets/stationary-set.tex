% id: sets.stationary-set
% term: Stationary subset of a cardinal
% related: sets.club-set, sets.regular-cardinal
% source: https://en.wikipedia.org/wiki/Stationary_set
% status: draft

For an uncountable regular cardinal $\kappa$, a subset $S\subseteq\kappa$ is \emph{stationary} if it meets every closed unbounded subset of $\kappa$: $S\cap C\ne\varnothing$ for all club $C\subseteq\kappa$. Every stationary subset is unbounded, but an unbounded subset need not be stationary. This set-theoretic notion is unrelated to time-stationary stochastic processes.
