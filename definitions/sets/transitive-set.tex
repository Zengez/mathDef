% status: draft

A set $X$ is \emph{transitive} if every element of a member of $X$ is also a member of $X$; equivalently,
\[
\forall y\in X,\quad y\subseteq X.
\]
Every von Neumann ordinal is transitive, but a transitive set need not itself be an ordinal.
