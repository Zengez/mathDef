% term: Image of a set under a function
% related: functions.function, sets.subset
% source: https://en.wikipedia.org/wiki/Image_(mathematics)
% status: draft

For a function $f:X\to Y$ and a subset $A\subseteq X$, the \emph{direct image} of $A$ under $f$ is $f[A]=\{f(a):a\in A\}\subseteq Y$. The image of the empty subset is empty; the image of an intersection need not equal the intersection of the images without injectivity.
