A \emph{limit ordinal} is a nonzero ordinal $\lambda$ that is not a successor ordinal, so there is no $\beta$ with $\lambda=\beta+1$. In the von Neumann representation, this is equivalent to $\lambda=\bigcup_{\beta<\lambda}\beta$. The first infinite ordinal $\omega$ is the least nonzero limit ordinal.
