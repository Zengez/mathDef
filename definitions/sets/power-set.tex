% id: sets.power-set
% term: Power set
% related: sets.set, sets.subset
% source: https://en.wikipedia.org/wiki/Power_set

For any set $A$, its \emph{power set} is the set of all subsets of $A$:
\[
\mathcal P(A)=\{B:B\subseteq A\}.
\]
In particular $\varnothing\in\mathcal P(A)$ and $A\in\mathcal P(A)$. The power-set axiom guarantees its existence in ZFC; Cantor's theorem gives $|\mathcal P(A)|>|A|$.
