For real $\nu>-1$ and $x>0$, the \emph{Bessel function of the first kind} is $J_\nu(x)=\sum_{k=0}^\infty\frac{(-1)^k}{k!\,\Gamma(k+\nu+1)}(x/2)^{2k+\nu}$. It satisfies $x^2y''+xy'+(x^2-\nu^2)y=0$.
