An \emph{analytic continuation} carries a holomorphic function element (a function on a neighborhood of a point) to overlapping neighborhoods by holomorphic functions agreeing on their common local domains. A \emph{direct extension} is the special case of a holomorphic function $F$ on a larger connected domain $V\supseteq U$ with $F|_U=f$. More generally, continuation along a path uses a compatible chain of local elements and need not produce a single-valued holomorphic function on all paths simultaneously.
