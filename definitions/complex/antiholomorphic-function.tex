A function $f:U\to\mathbb C$ on an open set $U\subseteq\mathbb C$ is \emph{antiholomorphic} if the function $z\mapsto\overline{f(z)}$ is holomorphic on $U$. Equivalently, it can locally be represented by a convergent power series in $\overline{z-z_0}$ at each $z_0\in U$. A continuously real-differentiable function is antiholomorphic exactly when $\partial f/\partial z=0$.
