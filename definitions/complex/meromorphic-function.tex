% term: Meromorphic function
% related: complex.holomorphic-function, complex.pole
% source: https://en.wikipedia.org/wiki/Meromorphic_function#Terminology
% status: draft

A function $f$ is \emph{meromorphic} on a connected plane domain $U$ if it is holomorphic on $U$ except at a discrete set of poles; these poles are allowed to take the extended value $\infty$. Equivalently, near every point of $U$ it can be represented as a quotient $g/h$ of holomorphic functions with $h$ not identically zero locally. Equivalently, it is a holomorphic map $U\to\widehat{\mathbb C}$ that is not identically $\infty$.
