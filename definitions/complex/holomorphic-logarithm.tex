Let $U\subseteq\mathbb C\setminus\{0\}$ be open. A \emph{holomorphic branch of the logarithm} on $U$ is a holomorphic function $L:U\to\mathbb C$ for which $e^{L(z)}=z$ for every $z\in U$. Necessarily $L'(z)=1/z$. A global branch exists on each simply connected $U$ avoiding $0$, but need not exist on multiply connected domains; on a connected domain any two branches differ by a constant in $2\pi i\mathbb Z$.
