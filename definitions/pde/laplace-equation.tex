On an open set $\Omega\subseteq\mathbb R^n$, the \emph{Laplace equation} for a scalar-valued function $u$ is $\Delta u=0$, where $\Delta=\sum_{j=1}^n\partial_{x_j}^2$. A $C^2$ function satisfying this equation at every point of $\Omega$ is called \emph{harmonic}.
