% id: pde.wave-front-set
% term: Smooth wave front set of a distribution
% related: pde.singular-support, pde.distribution, pde.fourier-transform
% source: https://en.wikipedia.org/wiki/Wave_front_set
% status: draft

For $u\in\mathcal D'(\Omega)$ and $\xi_0\ne0$, a pair $(x_0,\xi_0)$ is \emph{absent from the wave front set} $\operatorname{WF}(u)$ if there are $\chi\in C_c^\infty(\Omega)$ with $\chi(x_0)\ne0$ and an open conic neighborhood $\Gamma$ of $\xi_0$ such that for every $N\ge0$ there is $C_N$ with $|\widehat{\chi u}(\xi)|\le C_N(1+|\xi|)^{-N}$ for $\xi\in\Gamma$. The wave front set comprises all pairs not satisfying this condition.
