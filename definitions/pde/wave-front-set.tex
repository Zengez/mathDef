% term: Smooth wave front set of a distribution
% related: pde.singular-support, pde.distribution, pde.fourier-transform
% source: https://en.wikipedia.org/wiki/Wave_front_set
% status: draft

For $u\in\mathcal D'(\Omega)$ and $\xi_0\ne0$, a pair $(x_0,\xi_0)$ is \emph{not in the smooth wave front set} $\operatorname{WF}(u)$ if some $\chi\in C_c^\infty(\Omega)$ satisfies $\chi(x_0)\ne0$ and there is an open conic neighborhood $\Gamma$ of $\xi_0$ such that, for every integer $N\ge0$,
\[
|\widehat{\chi u}(\xi)|\le C_N(1+|\xi|)^{-N}\quad(\xi\in\Gamma).
\]
Thus $\operatorname{WF}(u)$ is a closed conic subset of $T^*\Omega\setminus0$, whose projection to $\Omega$ is the singular support of $u$.
