% id: pde.fundamental-solution
% term: Fundamental solution of a linear PDE
% related: pde.distribution, pde.dirac-delta
% source: https://encyclopediaofmath.org/wiki/Sobolev_space
% status: draft

For a linear differential operator $L$, a \emph{fundamental solution} is a distribution $E$ satisfying $LE=\delta_0$ in the distributional sense.
