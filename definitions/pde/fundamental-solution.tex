% id: pde.fundamental-solution
% term: Fundamental solution of a linear PDE
% related: pde.distribution, pde.dirac-delta
% source: https://encyclopediaofmath.org/wiki/Fundamental_solution
% status: draft

For a constant-coefficient linear differential operator $L$ on $\mathbb R^n$, a \emph{fundamental solution} is a distribution $E$ such that $LE=\delta_0$. For a variable-coefficient operator, one instead typically uses a kernel $E(x,y)$ with $L_xE(x,y)=\delta_y$, with appropriate domain and boundary qualifications.
