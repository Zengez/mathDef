% term: Viscosity solution of a degenerate elliptic PDE
% related: pde.weak-solution, pde.elliptic-equation

% status: draft

Suppose $F(x,r,p,X)$ is continuous and nonincreasing in the symmetric-matrix variable $X$. For an open domain $\Omega\subseteq\mathbb R^n$, a continuous function $u:\Omega\to\mathbb R$ is a \emph{viscosity subsolution} of $F(x,u,Du,D^2u)=0$ if $F(x,u(x),D\phi(x),D^2\phi(x))\le0$ whenever a $C^2$ test function $\phi$ touches $u$ from above at $x\in\Omega$ (so $u-\phi$ has a local maximum of zero there). A \emph{supersolution} has the reversed inequality for test functions touching from below; a \emph{viscosity solution} is both.
