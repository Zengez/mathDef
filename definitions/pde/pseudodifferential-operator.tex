For a symbol $a\in S^m_{1,0}(\mathbb R^n\times\mathbb R^n)$, the \emph{pseudodifferential operator} $a(x,D)$ on Schwartz test functions is $a(x,D)u(x)=(2\pi)^{-n}\int_{\mathbb R^n}e^{ix\cdot\xi}a(x,\xi)\widehat u(\xi)\,d\xi$, where $\widehat u(\xi)=\int_{\mathbb R^n}e^{-ix\cdot\xi}u(x)\,dx$.
