% id: pde.elliptic-equation
% term: Uniformly elliptic second-order operator
% related: pde.poisson-equation, pde.laplacian
% source: https://encyclopediaofmath.org/wiki/Sobolev_space
% status: draft

A second-order operator $Lu=-\sum_{i,j}a^{ij}(x)\partial_{ij}u+\text{lower order terms}$ is \emph{uniformly elliptic} if the symmetric part of $(a^{ij}(x))$ satisfies $\sum_{i,j}a^{ij}(x)\xi_i\xi_j\ge\lambda|\xi|^2$ for some $\lambda>0$ uniformly in $x$.
