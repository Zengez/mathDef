% term: Smoothing operator with smooth kernel
% related: pde.distribution, pde.parametrix
% source: https://encyclopediaofmath.org/wiki/Pseudo-differential_operator
% status: draft

On an open set $\Omega\subseteq\mathbb R^n$, a \emph{properly supported smoothing integral operator} has a $C^\infty$ kernel $K(x,y)$ whose support projects properly to both factors, and acts by $Ru(x)=\int_\Omega K(x,y)u(y)\,dy$ for test functions $u$. It extends to an operator sending distributions to smooth functions.
