% id: pde.smoothing-operator
% term: Smoothing operator with smooth kernel
% related: pde.distribution, pde.parametrix
% source: https://www.mat.univie.ac.at/~stefan/files/ASIT/ASIT.pdf#page=103
% status: draft

On an open set $\Omega\subseteq\mathbb R^n$, a \emph{properly supported smoothing integral operator} has a $C^\infty$ kernel $K(x,y)$ whose support is proper over each factor and acts on test functions by
\[
Ru(x)=\int_\Omega K(x,y)u(y)\,dy.
\]
The smoothness of the kernel and proper support allow an extension mapping distributions on $\Omega$ to smooth functions on $\Omega$. Such operators are microlocally regularizing and belong to the pseudodifferential class of order $-\infty$ in the usual calculus.
