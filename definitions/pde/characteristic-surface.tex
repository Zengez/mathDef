% id: pde.characteristic-surface
% term: Characteristic hypersurface
% related: pde.principal-symbol, pde.hyperbolic-equation
% source: https://encyclopediaofmath.org/wiki/Sobolev_space
% status: draft

For a scalar differential operator with principal symbol $p_m(x,\xi)$, a smooth hypersurface $\phi(x)=0$ is \emph{characteristic} where $p_m(x,d\phi_x)=0$.
