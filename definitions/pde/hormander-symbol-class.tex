% term: Hörmander symbol class
% related: pde.principal-symbol, pde.pseudodifferential-operator

% status: draft

For an open $\Omega\subseteq\mathbb R^n$, $m\in\mathbb R$ and $0\le\delta<\rho\le1$, the \emph{Hörmander symbol class} $S^m_{\rho,\delta}(\Omega\times\mathbb R^n)$ consists of smooth $a(x,\xi)$ such that for every compact $K\Subset\Omega$ and multi-indices $\alpha,\beta$ one has
\[
|\partial_\xi^\alpha\partial_x^\beta a(x,\xi)|
\le C_{\alpha,\beta,K}(1+|\xi|)^{m-\rho|\alpha|+\delta|\beta|}
\]
for all $x\in K,\xi\in\mathbb R^n$. These are local-in-$x$ uniform estimates, not necessarily global bounds.
