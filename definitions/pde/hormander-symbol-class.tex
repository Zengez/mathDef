% id: pde.hormander-symbol-class
% term: Hörmander symbol class
% related: pde.principal-symbol, pde.pseudodifferential-operator
% source: https://encyclopediaofmath.org/wiki/Pseudo-differential_operator
% status: draft

For an open $\Omega\subseteq\mathbb R^n$, $m\in\mathbb R$, and $0\le\delta<\rho\le1$, the \emph{symbol class} $S^m_{\rho,\delta}(\Omega\times\mathbb R^n)$ consists of smooth $a(x,\xi)$ such that for every compact $K\Subset\Omega$ and multi-indices $\alpha,\beta$ there is $C_{\alpha,\beta,K}$ with $|\partial_\xi^\alpha\partial_x^\beta a(x,\xi)|\le C_{\alpha,\beta,K}(1+|\xi|)^{m-\rho|\alpha|+\delta|\beta|}$ for $x\in K$.
