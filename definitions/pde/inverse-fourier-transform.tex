% id: pde.inverse-fourier-transform
% term: Inverse Fourier transform
% related: pde.fourier-transform, pde.schwartz-space
% source: https://en.wikipedia.org/wiki/Fourier_transform#Definition
% status: draft

For $g\in L^1(\mathbb R^n)$ whose inverse is justified by Fourier inversion (for example a Schwartz function), the inverse transform in the convention $\widehat f(\xi)=\int f(x)e^{-ix\cdot\xi}\,dx$ is $f(x)=(2\pi)^{-n}\int_{\mathbb R^n}g(\xi)e^{ix\cdot\xi}\,d\xi$.
