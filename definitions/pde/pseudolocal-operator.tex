% status: draft

A linear operator $P$ acting on distributions is \emph{pseudolocal} if it does not create singularities at points where the input is smooth:
\[
\operatorname{sing\,supp}(Pu)\subseteq\operatorname{sing\,supp}(u)
\]
whenever both sides are defined. Standard properly supported pseudodifferential operators are pseudolocal; this inclusion concerns singular \emph{locations} rather than a full equality of wave front sets.
