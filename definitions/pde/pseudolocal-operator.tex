An operator $P$ on distributions is \emph{pseudolocal} if it does not create new singularities: $\operatorname{sing\,supp}(Pu)\subseteq\operatorname{sing\,supp}(u)$ whenever $Pu$ is defined. Standard properly supported pseudodifferential operators have this property.
