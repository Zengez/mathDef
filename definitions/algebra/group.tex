A \emph{group} is a set $G$ with an associative binary operation $(g,h)\mapsto gh$, an identity $e\in G$ satisfying $eg=ge=g$, and for each $g\in G$ an element $g^{-1}$ satisfying $gg^{-1}=g^{-1}g=e$. Commutativity is not required.
