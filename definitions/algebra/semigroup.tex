A \emph{semigroup} is a nonempty set $S$ with an associative binary operation $S\times S\to S$, written $(a,b)\mapsto ab$, satisfying $(ab)c=a(bc)$ for all $a,b,c\in S$. An identity element or inverses are not required. Some categorical conventions also allow the empty semigroup.
