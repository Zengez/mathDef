A \emph{binary operation} on a set $S$ is a function $\ast:S\times S\to S$. Its value at $(a,b)$ is commonly written $a\ast b$. Closure in $S$ is built into the codomain; associativity, commutativity and the existence of an identity are additional properties, not part of this definition.
