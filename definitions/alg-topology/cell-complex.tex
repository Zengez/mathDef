A \emph{CW complex} is a Hausdorff space $X$ with a cell decomposition such that each closed cell meets only finitely many open cells (closure finiteness) and a set $A\subseteq X$ is closed if and only if its intersection with the closure of each cell is closed there (weak topology). Equivalently, $X$ is built by successively attaching closed disks along boundary maps with the weak topology.
