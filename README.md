# mathDef

An interactive, searchable collection of mathematical definitions.

## Project goals

- Store mathematical terms, their definitions, and links to related defined terms in a version-controlled `definitions/` directory.
- Provide **separate** searches for term names and definition contents.
- Support an optional side-by-side view with independent search results.

**Status:** Initial project planning. The content format, interface, and implementation have not yet been finalized.
